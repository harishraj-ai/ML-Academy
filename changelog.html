Changelog & versions

Version 3.2, 5 November 2026. What changed and when, the exact library versions behind every output, and an automated way to re-check them.

Library versions

Every code output and notebook in the course was produced with these versions, in a Linux environment:

PackageVersion
python3.13.18
numpy2.5.3
pandas3.0.5
scikit-learn1.9.1
matplotlib3.11.2
scipy1.18.1
nbclient0.11.0
nbformat5.11.1

Newer versions usually give the same results, but defaults and random-number details occasionally change. If your numbers differ slightly from a lesson, compare these versions with yours (import sklearn; print(sklearn.__version__)).

Automated output checks

Last output check: 2026-11-05 12:59 (UTC+0000) — Checked 44 notebooks (493 code cells) in 382 s. Everything matches.

The course folder includes tools/check_outputs.py. It re-runs all 22 lesson notebooks and 8 project notebooks in a temporary copy, compares every printed output with the published one (allowing for tiny rounding differences), checks that lesson outputs still match what the lesson page shows, and writes tools/check_report.md. It also compares your library versions with the ones above. Nothing in the course is changed.

cd ML
python tools/check_outputs.py            # everything, about 2 minutes
python tools/check_outputs.py --only 6 8   # just Lessons 6 and 8

Run it after upgrading scikit-learn, NumPy or pandas. It needs numpy pandas scikit-learn matplotlib nbformat nbclient ipykernel.
