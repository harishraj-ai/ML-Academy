Setup

Run the code yourself

You can read every lesson without installing anything. To run the code examples, install Python 3, then in a terminal:

python3 -m venv ml-env
source ml-env/bin/activate        # on Windows: ml-env\Scripts\activate
pip install numpy pandas scikit-learn matplotlib jupyterlab
jupyter lab

JupyterLab opens in your browser. Every lesson has a ready-made notebook with all its code (and the expected outputs): use the Download Jupyter notebook button at the top of a lesson, open the file in JupyterLab, and press Shift+Enter to run each cell. All of them are in the notebooks folder.

Prefer paper? The printable workbook (PDF, about 590 pages) has every lesson with space to work the exercises by hand, and all answers at the back. Each lesson page also prints cleanly on its own.

Prefer plain Python scripts? ⬇ Download all the code (.zip) — every lesson as a .py file, the coding challenges, the four projects (starter and solution), the dataset and a pytest test suite that checks every script still gives the published results. Unzip it anywhere and see its README.

About

Accurate by design

Lessons are written to be complete on their own, and checked against trusted sources — the scikit-learn documentation, Google's Machine Learning Crash Course, Mathematics for Machine Learning and original papers. Every code example has been run and its output verified. Each lesson lists the sources used at the bottom.
