Before you start

No prerequisites — this is the starting point.

Where this fits: This optional lesson comes before everything else. If you can already read basic Python, NumPy and pandas, skip straight to Lesson 1.

1.Why Python — and how to use this lesson

Every lesson in this course has Python code. If you've never programmed, this lesson gives you exactly enough to read and run it: about an hour, no prior experience needed. You will learn the core of the language, then the two libraries that machine learning in Python is built on: NumPy for numbers in bulk and pandas for tables.

Python is popular for machine learning because it reads almost like English, and because the best ML libraries (scikit-learn, PyTorch, TensorFlow) use it. You don't need to memorise anything here — come back whenever a later lesson's code looks unfamiliar.

Learn by running

Each code box below is followed by the output Python actually printed. The best way to learn is to type the code yourself in the Lesson 0 notebook, run it, then change something and run it again.

2.Running Python code

Follow the Setup instructions once: they install Python and JupyterLab, a notebook that runs in your browser. A notebook is a list of cells. Type code in a cell and press Shift+Enter: the code runs and its output appears underneath. Download this lesson's notebook with the button at the top of the page.

The simplest program prints a message:

print("Hello, machine learning!")

Output:

Hello, machine learning!

print is a function: you give it something in brackets and it shows it. Text goes inside quotes. Anything after a # is a comment — a note for humans that Python ignores.

3.Values, variables and arithmetic

A variable is a name for a value. The = sign means "store this value under this name" (it is not the maths equals).

price = 72.5        # a decimal number (a float)
bedrooms = 3        # a whole number (an int)
city = "Chennai"     # text (a string)
print(price, bedrooms, city)

Output:

72.5 3 Chennai

Arithmetic works like a calculator. ** means "to the power of", / always gives a decimal, and // divides and drops the remainder.

print(7 + 2, 7 - 2, 7 * 2, 7 / 2)
print(7 // 2, 7 % 2, 2 ** 10)
area = 12.5 * 8     # a variable can hold the result of a calculation
print(area)

Output:

9 5 14 3.5
3 1 1024
100.0

You can change a variable at any time; the new value replaces the old one:

count = 1
count = count + 1   # take the old value, add 1, store it back
count += 1          # a shorter way to write the same thing
print(count)

Output:

3

4.Text and printing

Text values are called strings. An f-string (a string with f before the quote) lets you drop variables into text with curly brackets, and :.2f rounds a number to 2 decimal places:

name = "house 7"
price = 84.1234
print(f"{name} costs {price:.2f} lakh")
print(name.upper(), len(name))   # a method, and the length of the string

Output:

house 7 costs 84.12 lakh
HOUSE 7 7

5.Lists and indexing

A list holds several values in order, inside square brackets. Positions are counted from 0, not 1 — the first item is [0]. Negative positions count from the end.

prices = [58, 82, 55, 88, 96]
print(prices[0], prices[1], prices[-1])   # first, second, last
print(len(prices))                          # how many items

Output:

58 82 96
5

A slice [start:stop] takes items from start up to but not including stop:

print(prices[1:3])     # items at positions 1 and 2
print(prices[:2])      # the first two
print(prices[2:])      # from position 2 to the end
prices.append(61)      # add an item at the end
print(prices)

Output:

[82, 55]
[58, 82]
[55, 88, 96]
[58, 82, 55, 88, 96, 61]
The off-by-one trap

prices[1:3] has two items (positions 1 and 2), and the last item of a 5-item list is prices[4] — prices[5] is an error. Almost every beginner trips on this; it soon becomes natural.

6.Dictionaries

A dictionary stores values under names (keys) instead of positions — like a row of a table:

house = {"area": "Central", "size_m2": 120, "price_lakh": 88}
print(house["size_m2"])
house["sold_fast"] = True     # add a new key
print(house)

Output:

120
{'area': 'Central', 'size_m2': 120, 'price_lakh': 88, 'sold_fast': True}

7.Making decisions and repeating: if and for

if runs code only when a condition is true. The indented lines (4 spaces) belong to it — in Python, indentation is part of the syntax.

price = 96
if price > 90:
    print("expensive")
elif price > 60:
    print("mid-range")
else:
    print("affordable")

Output:

expensive

A for loop repeats its indented block once for each item:

prices = [58, 82, 55, 88]
total = 0
for p in prices:
    total = total + p
print("total:", total, " average:", total / len(prices))

Output:

total: 283  average: 70.75

range(n) gives the numbers 0 to n−1, handy for repeating something n times. A list comprehension builds a new list from an old one in one line:

for step in range(3):
    print("step", step)
squares = [x ** 2 for x in [1, 2, 3, 4]]
print(squares)

Output:

step 0
step 1
step 2
[1, 4, 9, 16]

8.Functions

A function packages code under a name so you can reuse it. def defines it, the brackets list its inputs, and return sends back the result. This one is the mean squared error from Lesson 1:

def mse(y_true, y_pred):
    total = 0
    for t, p in zip(y_true, y_pred):   # zip walks through both lists together
        total += (p - t) ** 2
    return total / len(y_true)

print(mse([3, 5, 7], [2.5, 5, 8]))

Output:

0.4166666666666667

9.Libraries and import

Python's real power is its libraries. import loads one; as gives it a short nickname. These three lines start almost every notebook in this course:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
print("NumPy", np.__version__, "and pandas", pd.__version__, "loaded")

Output:

NumPy 2.5.3 and pandas 3.0.5 loaded

10.NumPy: numbers in bulk

A NumPy array is like a list of numbers, but arithmetic applies to every element at once — no loop needed. This is called vectorisation, and it's both shorter and much faster.

x = np.array([1.0, 2.0, 3.0, 4.0])
print(x * 2)          # every element doubled
print(x + 10)
print(x ** 2)
print(x.mean(), x.sum(), x.max())

Output:

[2. 4. 6. 8.]
[11. 12. 13. 14.]
[ 1.  4.  9. 16.]
2.5 10.0 4.0

Arrays can have two dimensions — rows and columns, like a table of examples × features. .shape tells you the size, and axis=0 means "down the rows" (one result per column):

X = np.array([[120, 3, 4.0],
              [ 95, 2, 6.5],
              [150, 4, 12.0]])   # 3 houses × 3 features
print(X.shape)
print(X[0])           # the first row (house 1)
print(X[:, 0])        # the first column (sizes)
print(X.mean(axis=0)) # the average of each column

Output:

(3, 3)
[120.   3.   4.]
[120.  95. 150.]
[121.66666667   3.           7.5       ]

Comparisons give arrays of True/False, which you can use to filter. And @ multiplies a matrix by a vector — the dot product of each row with the weights (Lesson 2):

sizes = X[:, 0]
print(sizes > 100)
print(sizes[sizes > 100])
w = np.array([0.5, 2.0, -1.0])
print(X @ w)          # one prediction per house

Output:

[ True False  True]
[120. 150.]
[62. 45. 71.]

11.pandas: tables of data

pandas works with DataFrames — tables with named columns, like a spreadsheet. Let's load the course's running example, 12 houses in Chennai (houses.csv, in the data folder):

df = pd.read_csv("houses.csv")
print(df.shape)                # (rows, columns)
print(df.columns.tolist())

Output:

(12, 9)
['id', 'area', 'size_m2', 'bedrooms', 'dist_km', 'age_yrs', 'description', 'price_lakh', 'sold_fast']
print(df[["area", "size_m2", "price_lakh"]].head(4))   # the first 4 rows of three columns

Output:

      area  size_m2  price_lakh
0  Central       65          58
1  Central       90          82
2  Central      120          95
3   Suburb       80          55

Select one column with df["name"] (it behaves like a NumPy array) and filter rows with a condition in square brackets:

print(df["price_lakh"].mean())
big = df[df["size_m2"] > 120]
print(len(big), "houses over 120 m²")
print(big[["id", "size_m2", "price_lakh"]])

Output:

72.08333333333333
4 houses over 120 m²
    id  size_m2  price_lakh
5    6      140          79
7    8      150          84
9   10      130          50
11  12      125          96

groupby summarises by category, and you can create new columns from old ones:

print(df.groupby("area")["price_lakh"].mean().round(1))
df["price_per_m2"] = df["price_lakh"] / df["size_m2"]
print(df.sort_values("price_per_m2", ascending=False)[["id", "area", "price_per_m2"]].head(3).round(3))

Output:

area
Central      76.8
Outskirts    58.7
Suburb       76.4
Name: price_lakh, dtype: float64
    id     area  price_per_m2
10  11  Central         0.960
1    2  Central         0.911
0    1  Central         0.892

12.A first plot

matplotlib draws charts. A scatter plot of price against size is the first thing you'd look at before fitting a model (Lesson 6):

plt.figure(figsize=(5, 3.2))
plt.scatter(df["size_m2"], df["price_lakh"])
plt.xlabel("size (m²)")
plt.ylabel("price (lakh)")
plt.title("Chennai Homes")
plt.show()

13.Reading error messages

Errors are normal — professionals see them all day. Python stops and prints a traceback; the last line says what went wrong. Here are the ones you'll meet most, with the real messages:

print(prise)

Error:

NameError: name 'prise' is not defined

NameError: a typo, or a variable used before the cell that creates it was run. In notebooks, run cells from the top.

"Price: " + 72

Error:

TypeError: can only concatenate str (not "int") to str

TypeError: mixing types that don't go together. Fix: "Price: " + str(72), or an f-string.

prices = [58, 82, 55]
prices[3]

Error:

IndexError: list index out of range

IndexError: counting from 1 instead of 0 — the last of 3 items is prices[2].

np.array([1, 2, 3]) + np.array([1, 2])

Error:

ValueError: operands could not be broadcast together with shapes (3,) (2,)

ValueError (a shape mismatch): element-by-element arithmetic needs arrays of the same size. Print .shape to check — the single most useful debugging habit in machine learning.

When you're stuck

Read the last line of the error, then the line of your code it points to. Check spelling, brackets, quotes and indentation. Restart the notebook and run all cells from the top. Searching the exact error message online almost always finds an answer.

14.Questions beginners often ask

Do I have to finish this before Lesson 1?

No. Lesson 1 has very little code. Many people read Lessons 1–5 first and come back here when the code in later lessons starts to matter.

Which version of Python?

Any Python 3 from the last few years (3.9 or newer). Python 2 is obsolete; you won't meet it.

Can I break my computer by running code?

Not with anything in this course. The worst that happens is an error message — then you fix the cell and run it again.

Why do positions start at 0?

It's a convention most programming languages share: the position is "how many steps from the start". You'll stop noticing it within a day or two.

NumPy or pandas — when do I use which?

pandas for loading and exploring tables with named columns; NumPy for maths on arrays of numbers. Models in scikit-learn accept either, and df.to_numpy() converts a table into an array.

Common mistakes to avoid
  • Forgetting that positions start at 0, so a[3] is the fourth item and a slice a[1:3] has two items.
  • Mixing tabs and spaces, or forgetting to indent the lines under if, for or def.
  • Running notebook cells out of order, so a variable doesn't exist yet (NameError). Restart and run all cells from the top.
  • Using a plain list where you need a NumPy array: [1, 2] * 2 repeats the list, np.array([1, 2]) * 2 doubles the numbers.
  • Writing df["price"] > 80 and expecting the rows; you need df[df["price"] > 80].
Interview corner

Don't confuse

  • Python list vs NumPy array — Lists are containers; arrays are vectors.
  • View vs copy — NumPy slices share memory; lists don't.
  • * vs @ in NumPy — Star = side by side; at-sign = rows times columns.
  • .loc vs .iloc — i for integer position.

Hidden questions — answer in your head first, then open.

You compute MSE with np.mean((y_pred - y)**2) and get 2.33, but by hand it's 0.33. What went wrong?

The trap: The formula is right, so people check the maths.

A shape bug. If y_pred has shape (3, 1) and y has shape (3,), broadcasting turns y_pred - y into a 3×3 matrix of every prediction minus every target. For predictions 1, 2, 3 and targets 1, 2, 4 that gives 2.33 instead of 0.33. Flatten with .ravel() and check .shape before computing losses.

Why does 0.1 + 0.2 == 0.3 return False, and what should you do instead?

The trap: Assuming it's a Python bug.

Floats are stored in binary, where 0.1 can't be represented exactly; the sum is 0.30000000000000004. Compare with a tolerance: np.isclose(a, b) or abs(a - b) < 1e-9. This matters when testing model outputs or gradients.

You slice a NumPy array, edit the slice, and your original data changes. Why?

The trap: Expecting Python list behaviour.

NumPy slices are views sharing the same memory. Use .copy() when you need an independent array. Python list slices, by contrast, are copies.

pandas warns SettingWithCopyWarning after df[df.age > 30]['score'] = 0. Did the data change?

The trap: Ignoring warnings.

Probably not: the first indexing may return a copy, and the assignment changes the copy. Use one .loc call: df.loc[df.age > 30, 'score'] = 0.

15.Key takeaways

  • Variables name values: numbers, strings, lists (positions from 0) and dictionaries (named keys).
  • if decides, for repeats, def packages code into functions — and indentation marks which lines belong together.
  • NumPy arrays do arithmetic on every element at once; .shape, axis=, boolean filtering and @ are the tools you'll use most.
  • pandas DataFrames are tables: read_csv, df["col"], df[condition], groupby and new columns cover most everyday work.
  • Errors are information: read the last line first.

16.Check your understanding

1. What does [10, 20, 30, 40][1] give?

Positions start at 0, so position 1 is the second item, 20.

2. What does [10, 20, 30, 40][1:3] give?

A slice runs from the start position up to, but not including, the stop position: positions 1 and 2.

3. x = np.array([1, 2, 3]). What is x * 2?

NumPy applies arithmetic to every element. (With a plain Python list, * 2 would repeat the list instead.)

4. A NumPy array has shape (100, 5). What does X.mean(axis=0) return?

axis=0 averages down the rows, giving one result per column — here, the average of each of the 5 features.

5. Which line keeps only the rows of a DataFrame where the price is above 80?

The comparison makes a True/False column; putting it inside df[...] keeps the True rows. The first option only gives the True/False values.

Exercise 1By hand

For a = [3, 6, 9, 12, 15], what are (a) a[-2] and (b) a[1:4]?

Check your answers — for several numbers, separate them with commas:

Show solution
(a) a[-2] counts from the end: the second-to-last item, 12. (b) Positions 1, 2 and 3 (the stop position 4 is excluded): [6, 9, 12].
Exercise 2By hand

X = np.array([[1, 2, 3], [4, 5, 6]]). Give X.shape, X.sum(axis=0) and X[:, 1].

Check your answers — for several numbers, separate them with commas:

Show solution
Two rows and three columns: shape (2, 3). axis=0 adds down the rows, one total per column: [5, 7, 9]. X[:, 1] is every row, column 1 (the second column): [2, 5].
