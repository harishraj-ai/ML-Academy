Before you start

This lesson builds on:

  • Lesson 3: Derivatives & Gradients — A derivative is a slope; the gradient $\nabla L$ collects all partial derivatives and points uphill. Gradient descent steps the other way: $\mathbf{w} \leftarrow \mathbf{w} - \eta\nabla L$. The chain rule differentiates functions inside functions.
  • Lesson 7: Gradient Descent — Gradient descent trains almost any model: compute the gradient of the loss, step against it, repeat. The learning rate controls the step size; too large diverges. Mini-batches make it fast on big data.
  • Lesson 8: Logistic Regression — Logistic regression outputs a probability $p = \sigma(\mathbf{w}\cdot\mathbf{x} + b)$, is trained with log loss, and classifies with a threshold (often 0.5), giving a straight decision boundary.

Where this fits: Starts Part 5. Neural networks combine everything so far — dot products, activations like the sigmoid, losses, the chain rule and gradient descent.

1.Why neural networks?

Every model so far has a fixed shape: a straight line, a set of boxes, a kernel. Neural networks learn their own internal features. Stack enough simple units together and the network can represent extremely complicated relationships — recognising faces, translating languages, generating text. Modern AI is built on them.

The good news: you already know every ingredient. A neuron is logistic regression (Lesson 8). Training is gradient descent (Lesson 7). And the famous backpropagation algorithm is the chain rule (Lesson 3), applied carefully. In this lesson you'll compute a full forward and backward pass by hand, then write a working network in about 20 lines of NumPy.

2.The artificial neuron

Picture itDeciding whether to go for a run, you weigh the weather, how tired you are and whether a friend is coming, then decide yes or no. A neuron does the same: weigh the inputs, add them up, and squash the total into a decision.

A neuron takes inputs $x_1, \dots, x_d$, multiplies each by a weight, adds a bias, and passes the result through an activation function $g$:

$$z = \mathbf{w}\cdot\mathbf{x} + b, \qquad a = g(z)$$

With $g = $ sigmoid, a single neuron is logistic regression. It draws one straight boundary. To learn more complex shapes, we connect many neurons in layers.

Loosely inspired by the brain

A biological neuron receives signals from other neurons, and "fires" if the combined signal is strong enough. The artificial version is a very simplified mathematical cartoon of that: weighted inputs, summed, then squashed. Don't take the analogy too far — what matters is the maths.

Read the formulaOne neuron
$$\htmlClass{fd-1}{a} = \htmlClass{fd-2}{g}\big(\htmlClass{fd-3}{\mathbf{w}\cdot\mathbf{x}} + \htmlClass{fd-4}{b}\big)$$
  • a — the neuron's output (activation)
  • g — activation function, e.g. ReLU — adds the non-linearity
  • w · x — weighted sum of the inputs
  • b — bias — shifts the threshold

Hover over (or tap) a part to highlight it in the formula.

3.Why one neuron isn't enough: XOR

The XOR ("exclusive or") function outputs 1 when exactly one input is 1:

x1x2XOR
000
011
101
110

Plot the four points: the 1s sit on one diagonal, the 0s on the other. No single straight line separates them, so no single neuron (and no logistic regression) can learn XOR. But two neurons can each draw one line, and a third neuron can combine their answers — "above line A and below line B". That's the power of hidden layers: they create new features that make the problem easy for the next layer.

4.Layers: the multilayer perceptron

A multilayer perceptron (MLP), or feed-forward network, has:

  • an input layer — the features (no computation);
  • one or more hidden layers — neurons whose outputs feed the next layer;
  • an output layer — the prediction.

Each layer does a matrix multiplication (Lesson 2) followed by an activation:

$$\mathbf{h} = g\big(W^{[1]}\mathbf{x} + \mathbf{b}^{[1]}\big), \qquad \hat{y} = \sigma\big(\mathbf{v}\cdot\mathbf{h} + c\big)$$

Here $W^{[1]}$ is a matrix with one row of weights per hidden neuron. With $d$ inputs and $m$ hidden neurons it has shape $m \times d$, plus $m$ biases.

Why activation functions are essential

Without $g$, two layers collapse into one: $V(W\mathbf{x}) = (VW)\mathbf{x}$, still a linear model. The non-linear activation is what lets depth add power.

5.Activation functions

NameFormulaRangeTypical use
ReLU$\max(0, z)$$[0, \infty)$Default for hidden layers
Sigmoid$\frac{1}{1 + e^{-z}}$$(0, 1)$Output for binary classification
tanh$\frac{e^z - e^{-z}}{e^z + e^{-z}}$$(-1, 1)$Hidden layers (zero-centred)
Softmax$\frac{e^{z_k}}{\sum_j e^{z_j}}$probabilities summing to 1Output for multi-class

Their derivatives, needed for training: ReLU′ is 1 if $z > 0$ else 0; $\sigma'(z) = \sigma(z)(1 - \sigma(z))$; $\tanh'(z) = 1 - \tanh^2(z)$. ReLU is popular because it's cheap and its gradient doesn't shrink for positive inputs, which helps deep networks train (Lesson 19).

6.Worked example: a forward pass

Worked example — a 2-2-1 network

Inputs $\mathbf{x} = (1, 0)$, true label $y = 1$. Two sigmoid hidden neurons, one sigmoid output, all biases 0.

Hidden weights: neuron 1 has $(0.5,\ 0.3)$, neuron 2 has $(-0.5,\ 0.8)$. Output weights $\mathbf{v} = (1,\ -1)$.

Hidden layer:
$z_1 = 0.5\cdot1 + 0.3\cdot0 = 0.5 \Rightarrow h_1 = \sigma(0.5) \approx 0.6225$
$z_2 = -0.5\cdot1 + 0.8\cdot0 = -0.5 \Rightarrow h_2 = \sigma(-0.5) \approx 0.3775$

Output: $z = 1\cdot0.6225 - 1\cdot0.3775 = 0.2449 \Rightarrow p = \sigma(0.2449) \approx 0.5609$.

Loss (log loss, Lesson 8): $L = -\ln 0.5609 \approx 0.578$. The network gives only a 56% chance to the correct answer. Let's teach it.

Make sense of it

The situation: A tiny network decides whether to approve something from two yes/no signals. Each hidden neuron is a small feature detector; the output neuron weighs their opinions.

What the result tells you: Neuron 1 likes input 1 (output 0.62); neuron 2 dislikes it (0.38). The output adds them with weights +1 and −1, giving 0.56 — barely leaning towards "yes".

What if…?

  • Other input $\mathbf{x} = (0, 1)$: the hidden outputs become 0.57 and 0.69, and $p$ drops to 0.47 — the network now leans "no" (loss 0.75 if the truth is 1).
  • ReLU hidden neurons instead of sigmoid: $h = (0.5, 0)$ and $p = 0.62$ — neuron 2 is switched off entirely for this input.
  • All weights 0: both hidden neurons output exactly 0.5 and $p = 0.5$. Worse, both neurons get identical gradients forever, so they never become different — which is why weights start random.

Why it matters in ML: A forward pass is just repeated dot products (Lesson 2) followed by a non-linear function. Stacking layers lets the network build complex features out of simple ones.

7.Backpropagation: the chain rule, backwards

In plain wordsBackpropagation works out, for every weight, how much it contributed to the error — starting at the output and passing the blame backwards layer by layer. Then each weight is nudged to reduce the error.

To update every weight we need $\partial L/\partial(\text{weight})$. The loss depends on the weights through a chain: weight → hidden $z$ → hidden $h$ → output $z$ → $p$ → $L$. The chain rule multiplies the local derivatives along this path. Backpropagation organises it efficiently: compute an "error signal" $\delta$ at the output, then pass it backwards layer by layer, reusing each result.

  1. Output error. For sigmoid + log loss, Lesson 8 showed the derivative w.r.t. the output's $z$ simplifies to $\delta_{\text{out}} = p - y$.
  2. Output weights. $\frac{\partial L}{\partial v_j} = \delta_{\text{out}}\cdot h_j$ and $\frac{\partial L}{\partial c} = \delta_{\text{out}}$.
  3. Pass the error back. Each hidden neuron gets the output error times the weight connecting it, times its own activation derivative: $\delta_j = \delta_{\text{out}}\cdot v_j\cdot g'(z_j)$.
  4. Hidden weights. $\frac{\partial L}{\partial W_{jk}} = \delta_j\cdot x_k$ and $\frac{\partial L}{\partial b_j} = \delta_j$.
  5. Update all weights with gradient descent: $w \leftarrow w - \eta\,\frac{\partial L}{\partial w}$.

Every gradient has the same pattern: (error signal arriving at a neuron) × (input that came into it).

Worked example — backward pass and one update

Continuing from the forward pass ($p = 0.5609$, $y = 1$, $h = (0.6225, 0.3775)$).

1. Output error: $\delta_{\text{out}} = 0.5609 - 1 = -0.4391$.

2. Output weights: $\frac{\partial L}{\partial v_1} = -0.4391\times0.6225 \approx -0.2733$, $\ \frac{\partial L}{\partial v_2} = -0.4391\times0.3775 \approx -0.1658$, $\ \frac{\partial L}{\partial c} = -0.4391$.

3. Hidden errors (sigmoid derivative $h(1-h) = 0.6225\times0.3775 \approx 0.2350$ for both):
$\delta_1 = -0.4391\times(1)\times0.2350 \approx -0.1032$
$\delta_2 = -0.4391\times(-1)\times0.2350 \approx +0.1032$

4. Hidden weights: multiply by the inputs $(1, 0)$: neuron 1's gradients are $(-0.1032,\ 0)$, neuron 2's are $(0.1032,\ 0)$. (Weights from $x_2 = 0$ get zero gradient — that input contributed nothing.)

5. Update with $\eta = 1$:
$v = (1 + 0.2733,\ -1 + 0.1658) = (1.2733,\ -0.8342)$, $\ c = 0.4391$
neuron 1: $(0.5 + 0.1032,\ 0.3) = (0.6032,\ 0.3)$; neuron 2: $(-0.5 - 0.1032,\ 0.8) = (-0.6032,\ 0.8)$

Check: running the forward pass again gives $p \approx 0.7245$ and loss $\approx 0.322$ (down from 0.578). One step of backpropagation made the network noticeably more confident in the right answer.

Make sense of it

The situation: The network gave 56% to the right answer. Backpropagation works out how much each weight was to blame, and nudges each one.

What the result tells you: The output error −0.44 says "too low". It flows back through each weight: weights that pushed the wrong way get the biggest corrections. After one step the network gives 72%.

What if…?

  • Learning rate 0.1: $p$ rises only to 0.579 (loss 0.547) — a small, safe step.
  • Learning rate 5: $p$ jumps to 0.98 in one step — great on this one example, but steps this big usually make training on many examples unstable.
  • If the truth were 0: every gradient flips sign; one step ($\eta = 1$) lowers $p$ to 0.34 and the loss from 0.82 to 0.41.

Why it matters in ML: Every deep-learning framework does exactly this, automatically, for millions of weights: forward pass, loss, backward pass (the chain rule, Lesson 3), update (gradient descent, Lesson 7).

Why it's efficient

Backpropagation computes the gradients for all weights in roughly the same time as one forward pass, by reusing the $\delta$ values. That's what makes training networks with millions or billions of weights possible. It was popularised for neural networks by Rumelhart, Hinton and Williams in 1986.

Step-by-step derivationDerive the gradient for one hidden weight
  1. $$\frac{\partial L}{\partial W_{jk}} = \frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial h_j}\cdot\frac{\partial h_j}{\partial z_j}\cdot\frac{\partial z_j}{\partial W_{jk}}$$

    Chain rule along the path $W_{jk} \to z_j \to h_j \to z \to L$.

  2. $$\frac{\partial L}{\partial z} = p - y$$

    Sigmoid output with log loss (Lesson 8).

  3. $$\frac{\partial z}{\partial h_j} = v_j$$

    Because $z = \sum_j v_jh_j + c$.

  4. $$\frac{\partial h_j}{\partial z_j} = g'(z_j)$$

    The hidden activation's derivative.

  5. $$\frac{\partial z_j}{\partial W_{jk}} = x_k$$

    Because $z_j = \sum_k W_{jk}x_k + b_j$.

  6. $$\frac{\partial L}{\partial W_{jk}} = \underbrace{(p - y)\,v_j\,g'(z_j)}_{\delta_j}\cdot x_k$$

    Multiply: error signal × input — exactly the backprop rule.

Advanced · optionalThe softmax + cross-entropy gradient

With $K$ classes, the output layer computes $p_k = e^{z_k}/\sum_j e^{z_j}$ and the loss for a one-hot label $\mathbf{y}$ is $\ell = -\sum_k y_k\ln p_k$. The softmax derivative is $\partial p_k/\partial z_j = p_k(\mathbb{1}[k=j] - p_j)$. Therefore

$$\frac{\partial \ell}{\partial z_j} = -\sum_k \frac{y_k}{p_k}\,p_k(\mathbb{1}[k=j]-p_j) = -y_j + p_j\sum_k y_k = p_j - y_j.$$

Exactly the same "prediction minus target" error signal as the sigmoid + log loss in this lesson — which is why softmax and cross-entropy are always paired, and why frameworks fuse them into one numerically stable operation.

8.The same thing with matrices

In plain wordsThe same calculations are written with matrices so that the computer can process many examples at once.

For a batch of $n$ examples (rows of $X$), with tanh hidden units and a sigmoid output:

$$H = \tanh(XW_1 + \mathbf{b}_1), \qquad P = \sigma(HW_2 + b_2)$$

Backward:

$$\Delta_2 = \tfrac{1}{n}(P - Y), \quad \frac{\partial L}{\partial W_2} = H^\top\Delta_2, \quad \Delta_1 = (\Delta_2W_2^\top)\odot(1 - H^2), \quad \frac{\partial L}{\partial W_1} = X^\top\Delta_1$$

($\odot$ means element-wise multiplication; $1 - H^2$ is tanh's derivative.) These four lines are exactly what the NumPy code below does.

10.Training in practice

  • Initialisation: start weights as small random numbers, never all equal. If every weight is the same, every hidden neuron computes the same thing and gets the same gradient — they'd never become different.
  • Scale inputs (standardise), as with any gradient-descent model.
  • Mini-batches and epochs (Lesson 7): update on small random batches; one epoch is one pass over the data.
  • Watch the validation loss and stop when it starts rising (early stopping); use L2 regularization (Lesson 10).
  • Size: more neurons and layers give more capacity — and more risk of overfitting.
Universal approximation

A famous result says that a network with just one hidden layer and enough neurons can approximate any reasonable continuous function as closely as you like. It doesn't say how many neurons you'd need, or that training will find the right weights — in practice, deeper networks with fewer neurons per layer usually learn much more efficiently.

11.In Python: a network from scratch

A 2-4-1 network learning XOR with NumPy — every line corresponds to an equation above:

import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
Y = np.array([[0], [1], [1], [0]], dtype=float)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

rng = np.random.default_rng(1)
W1 = rng.normal(0, 1, (2, 4)); b1 = np.zeros(4)     # input -> 4 hidden neurons
W2 = rng.normal(0, 1, (4, 1)); b2 = np.zeros(1)     # hidden -> output
lr = 0.5

for step in range(5001):
    # forward pass
    H = np.tanh(X @ W1 + b1)
    P = sigmoid(H @ W2 + b2)
    loss = -np.mean(Y * np.log(P) + (1 - Y) * np.log(1 - P))
    # backward pass (backpropagation)
    dZ2 = (P - Y) / len(X)
    dW2 = H.T @ dZ2;  db2 = dZ2.sum(axis=0)
    dZ1 = (dZ2 @ W2.T) * (1 - H ** 2)          # tanh'(z) = 1 - tanh(z)^2
    dW1 = X.T @ dZ1;  db1 = dZ1.sum(axis=0)
    # gradient descent update
    W1 -= lr * dW1;  b1 -= lr * db1
    W2 -= lr * dW2;  b2 -= lr * db2
    if step in (0, 1000, 5000):
        print(step, round(loss, 4))

print(P.round(3).ravel())

With scikit-learn, on the 8×8 handwritten digits (64 inputs, 10 classes):

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)

mlp = make_pipeline(StandardScaler(),
                    MLPClassifier(hidden_layer_sizes=(64,), max_iter=500, random_state=0))
mlp.fit(X_train, y_train)
print(round(mlp.score(X_train, y_train), 3), round(mlp.score(X_test, y_test), 3))

Output: 1.0 0.973. One hidden layer of 64 ReLU neurons (scikit-learn's default activation) — $64\times64 + 64 + 64\times10 + 10 = 4{,}810$ parameters — reaches 97.3% on unseen digits, a little above logistic regression on the same split (96.9%). The 100% training score hints at mild overfitting; increasing alpha (L2) or using early_stopping=True are the usual remedies.

12.Running example: Chennai Homes

A tiny neural network (one hidden layer of 4 neurons) learns to predict fast sales from size, distance and age, getting every house right even in leave-one-out evaluation. On such small, simple data, though, the decision tree's rule works just as well and is far easier to explain.

Same 12 houses as Lesson 1. With so little data, treat the numbers as an illustration of the method, not as reliable estimates.

import pandas as pd
import numpy as np
df = pd.read_csv("houses.csv")   # download it from Lesson 1
from sklearn.neural_network import MLPClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, LeaveOneOut
cols = ["size_m2", "dist_km", "age_yrs"]
mlp = make_pipeline(StandardScaler(), MLPClassifier(hidden_layer_sizes=(4,), max_iter=5000, random_state=0))
print("training accuracy:", mlp.fit(df[cols], df["sold_fast"]).score(df[cols], df["sold_fast"]))
print("leave-one-out accuracy:", round(cross_val_score(mlp, df[cols], df["sold_fast"], cv=LeaveOneOut()).mean(), 2))

Where this is used
  • Handwriting and image recognition
  • The foundation of every modern deep learning system

Choose it when: Large datasets with complex patterns, especially images, audio and text.

Think twice when: Small tabular datasets — gradient boosting or logistic regression are usually better and simpler.

Misconceptions to unlearn

MythNeural networks work like the human brain.

RealityThey're loosely inspired by neurons, but they are mathematical functions trained by gradient descent.

MythDeeper networks are always better.

RealityMore depth needs more data and careful training; on small tabular data, simple models often win.

Responsible AI · Fragile and opaque

Neural networks can be fooled by tiny, deliberately chosen changes to their input: Szegedy et al. (2014) and Goodfellow et al. (2015) showed images altered imperceptibly to humans that networks misclassify with high confidence. Their reasoning is also hard to inspect. For safety-critical uses, test robustness, monitor behaviour after deployment, and don't treat confidence as correctness.

13.Questions beginners often ask

How many layers and neurons should I use?

Start small (one or two hidden layers), check for underfitting or overfitting, and grow or regularise from there.

Why ReLU instead of sigmoid in hidden layers?

ReLU is cheap and its gradient doesn't shrink for positive inputs, so deep networks train much better.

Is a neural network always better?

No. On small tabular datasets, gradient boosting or logistic regression is often more accurate and far simpler.

Common mistakes to avoid
  • Initialising all weights to the same value (usually zero).
  • Forgetting non-linear activations between layers.
  • Not scaling inputs, which slows or stalls training.
Interview corner

Don't confuse

  • Activation function vs loss function — Inside the network vs at the end.
  • Forward pass vs backward pass — Predict, then assign blame.
  • Dropout vs batch normalisation — Random silence vs steady scaling.

Hidden questions — answer in your head first, then open.

Why does a neural network need non-linear activation functions?

The trap: "To make outputs between 0 and 1."

Without them, stacked layers collapse into a single linear layer: $W_2(W_1\mathbf{x}) = (W_2W_1)\mathbf{x}$. However deep, the network could only draw straight boundaries. The non-linearity is what lets depth build complex functions.

What happens if you initialise all weights to zero?

The trap: "Training just starts slowly."

Every neuron in a layer computes the same output and receives the same gradient, so they stay identical forever — the layer behaves like a single neuron. Random initialisation breaks this symmetry. (Biases can start at zero.)

Why did sigmoid hidden layers make deep networks hard to train?

The trap: Blaming the data.

The sigmoid's slope is at most 0.25, and nearly 0 for large inputs. Backpropagation multiplies one such factor per layer, so gradients shrink exponentially in early layers: the vanishing-gradient problem. ReLU (slope 1 for positive inputs), careful initialisation, batch normalisation and residual connections fixed it.

What is a "dying ReLU"?

The trap: Thinking ReLU has no downsides.

If a neuron's input becomes negative for every example (often after a large update), it outputs 0 and gets zero gradient, so it never recovers. Lower learning rates, careful initialisation or Leaky ReLU help.

14.Key takeaways

  • A neuron computes $g(\mathbf{w}\cdot\mathbf{x} + b)$; layers of neurons are matrix multiplications plus activations.
  • Non-linear activations (ReLU, tanh, sigmoid) are what make hidden layers useful — they let networks solve problems like XOR.
  • Backpropagation is the chain rule: compute $\delta_{\text{out}} = p - y$, pass errors backwards ($\delta_j = \delta_{\text{out}}v_jg'(z_j)$), and each gradient = error × input.
  • Training = forward pass, loss, backward pass, gradient-descent update, repeated over mini-batches.
  • Initialise randomly, scale inputs, and watch validation loss to avoid overfitting.

15.Check your understanding

1. Why can't a single neuron learn XOR?

The 1s and 0s lie on opposite diagonals; separating them needs at least two lines combined, i.e. a hidden layer.

2. What happens if you remove all activation functions from a deep network?

A chain of linear maps is still linear: $V(W\mathbf{x}) = (VW)\mathbf{x}$.

3. What is ReLU(−3)?

$\max(0, -3) = 0$.

4. Output $p = 0.8$, label $y = 0$, hidden activation $h_1 = 0.5$. What is $\partial L/\partial v_1$ (sigmoid + log loss)?

$\delta_{\text{out}} = p - y = 0.8$; $\partial L/\partial v_1 = 0.8\times0.5 = 0.4$. Positive, so $v_1$ will decrease.

5. Why must weights be initialised randomly rather than all zeros?

Random initialisation "breaks the symmetry" so each hidden neuron can specialise.
