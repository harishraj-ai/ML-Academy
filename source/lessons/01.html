Welcome: what you'll be able to do

By the end of this lesson you will be able to explain, in plain words, what machine learning is, how it differs from ordinary programming, and what the words model, feature, label, training and prediction mean. You'll also "be the algorithm" yourself in an interactive demo — which is the fastest way to understand what a computer does when it learns.

No maths or programming knowledge is needed for this lesson. Everything is built up from scratch.

Two ways to make a computer smart

Imagine you want a program that decides whether an email is spam.

Way 1 — write the rules yourself. You sit down and write instructions:

if "free money" in email: spam
if "winner" in subject and sender is unknown: spam
...

This is traditional programming. It works for simple problems, but it breaks down quickly: spammers change their wording, there are thousands of special cases, and you can never write them all.

Way 2 — show examples and let the computer find the rules. You collect 100,000 emails that people have already marked "spam" or "not spam", and give them to a learning algorithm. The algorithm looks for patterns — which words, senders and formats tend to appear in spam — and produces a program that can classify new emails it has never seen.

That second way is machine learning.

Definition

Google's Machine Learning course puts it like this: machine learning is "a way to train software, called a model, to make predictions or generate content using data."

Analogy

Think about how a child learns what a "dog" is. Nobody gives the child a rulebook ("four legs, fur, tail, barks…"). Instead, the child sees many dogs, and many things that are not dogs, and gradually builds an internal sense of "dog-ness". If they call a cat a dog, someone corrects them, and their understanding adjusts. Machine learning works the same way: examples + correction = learning.

Where you already meet ML

  • Your phone's keyboard predicts your next word.
  • Maps apps predict how long a trip will take.
  • Streaming services recommend what to watch next.
  • Banks flag card transactions that look fraudulent.
  • Photo apps group pictures by the faces in them.
  • Chatbots and image generators create new text and pictures.

Each of these has the same core: a model that turns some input (your typing, a route, your viewing history) into an output (a word, a time, a recommendation).

Let's use one running example: predicting the price of a house.

  • Example (also called a sample, row, or data point): one house — one row of the table.
  • Features (inputs, usually written $x$): the facts we know about each example — size, bedrooms, distance. A house is described by a list of features, e.g. $x = (50, 1, 2)$.
  • Label (target, output, written $y$): the thing we want to predict — price. For the first house, $y = 210$.
  • Dataset: the whole table — many examples, each with features and (usually) a label.
  • Model: a function that takes features and outputs a prediction, written $\hat{y}$ ("y-hat"). The hat means "our guess", as opposed to the true $y$.
  • Parameters (or weights): the adjustable numbers inside the model. Learning means finding good values for them.
  • Training: the process of adjusting the parameters so predictions match the labels in the dataset.
  • Inference (prediction): using the trained model on new examples whose labels we don't know.
Notation you'll see everywhere

$x$ = features, $y$ = true label, $\hat{y}$ = predicted label, $n$ = number of examples, $d$ = number of features. A subscript picks out one example: $x_3$ and $y_3$ are the features and label of example 3.

The main types of machine learning

1. Supervised learning

Every training example comes with the right answer (the label). The model learns the mapping from features to label. Two flavours:

  • Regression — the label is a number. "What will this house sell for?" → 340.
  • Classification — the label is a category. "Is this email spam?" → yes / no. "Which digit is in this image?" → 0–9.

2. Unsupervised learning

There are no labels. The goal is to discover structure in the data on its own — for example, grouping customers into segments with similar shopping habits (clustering), or compressing many features into a few (dimensionality reduction).

3. Reinforcement learning

An agent takes actions in an environment and receives rewards or penalties, learning by trial and error which actions lead to the most reward — the way a game-playing program learns to win.

4. Generative AI

Models that create new content — text, images, audio — learned from huge datasets. Chatbots and image generators are examples.

This course focuses on supervised and unsupervised learning, which are the foundation for everything else.

How does a model actually "learn"?

Let's make it concrete with the simplest possible model. Suppose we predict house price from size only, using a straight line:

$$\hat{y} = w \cdot x + b$$
  • $x$ is the size of the house,
  • $\hat{y}$ is the predicted price,
  • $w$ (the weight, or slope) says how much the price rises per extra m²,
  • $b$ (the bias, or intercept) is the starting price when size is 0.

$w$ and $b$ are the model's parameters. Different values give different lines. Learning means finding the $w$ and $b$ that make the line fit the data best. To do that we need three ingredients:

  1. A model with adjustable parameters — here, the line $\hat{y} = wx + b$.
  2. A way to measure how wrong it is — called the loss (or cost).
  3. A way to improve the parameters — an optimisation method that changes $w$ and $b$ to reduce the loss.

Measuring wrongness: the loss

For each house, the error (or residual) is the gap between prediction and truth: $\hat{y}_i - y_i$. Some errors are positive, some negative, so we square them (making all positive, and punishing big errors more) and take the average. This is the mean squared error (MSE):

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

Reading the symbols: $\sum_{i=1}^{n}$ means "add up, for every example $i$ from 1 to $n$". So: compute the squared error for every house, add them up, divide by how many houses there are.

Improving the parameters

You could guess randomly, but that's slow. Instead, algorithms use calculus to work out which direction to nudge each parameter so the loss goes down, take a small step, and repeat. This is called gradient descent, and you'll build it yourself in Lesson 7 after learning derivatives in Lesson 3.

Try it: be the learning algorithm

Below are some houses (dots). Move the sliders to change $w$ and $b$ and try to make the line fit the dots. Watch the MSE: your goal is to make it as small as possible. The red vertical lines are the errors. When you're done, press Show best fit to see what an algorithm finds.

What you just did — adjust parameters, check the loss, adjust again — is exactly what a learning algorithm does. The only difference is that the computer does it with precise maths, millions of times faster, and with thousands of parameters instead of two.

The machine learning workflow

Real projects follow roughly the same steps:

  1. Define the problem. What exactly do you want to predict, and how will you measure success?
  2. Collect data. Gather examples with features (and labels, for supervised learning).
  3. Split the data. Keep some examples aside as a test set that the model never sees during training, so you can check honestly how it does on new data (Lesson 5).
  4. Prepare the data. Clean errors, handle missing values, convert text categories to numbers (Lesson 20).
  5. Train a model. Start simple, then try better models.
  6. Evaluate. Measure performance on data the model hasn't seen (Lesson 9).
  7. Deploy and monitor. Use the model in the real world and watch that it keeps working.
The one big trap

A model can memorise its training data — like a student who memorises the answers to last year's exam without understanding the subject. It looks perfect on data it has seen and fails on new data. This is called overfitting, and avoiding it is one of the central themes of this course.

Your first ML code

Here is the same "fit a line" task in Python, using the popular scikit-learn library. Don't worry about every detail yet — notice the pattern: create a model, fit it to data, then predict.

from sklearn.linear_model import LinearRegression

# features: house size in 100 m² (each row is one house)
X = [[1], [2], [3], [4], [5]]
# labels: price in units of 100,000 USD
y = [2.1, 3.9, 6.2, 7.8, 10.1]

model = LinearRegression()   # 1. choose a model
model.fit(X, y)              # 2. train: find the best w and b

print(model.coef_, model.intercept_)   # the learned w and b
print(model.predict([[6]]))            # 3. predict a new 600 m² house

Running this prints a slope of about 1.99, an intercept of about 0.05, and a prediction of about 12 (i.e. 1.2 million USD) for the new house. To run it yourself, see the setup steps on the home page.

Key takeaways

  • Machine learning trains a model from data instead of hand-writing rules.
  • Data is made of examples, each with features $x$ and (in supervised learning) a label $y$.
  • Supervised learning has labels (regression = numbers, classification = categories); unsupervised learning finds structure without labels.
  • Learning = choosing parameters that minimise a loss, such as mean squared error.
  • The real goal is to do well on new data, not just the training data.

Check your understanding

1. A model predicts tomorrow's temperature in °C. What kind of problem is this?

The label is a number on a continuous scale, so it is regression. Classification would predict a category such as "hot / mild / cold".

2. In a dataset of emails labelled spam / not spam, what is the "label"?

The label is the answer we want to predict. Words and sender are features — the inputs.

3. Predictions are 3, 5 and true values are 4, 5. What is the MSE?

Errors are $-1$ and $0$; squared: $1$ and $0$; average $= (1+0)/2 = 0.5$.

4. You group shoppers by buying habits without any predefined categories. This is…

There are no labels — the algorithm discovers the groups itself. That is unsupervised learning (specifically clustering).

5. A model scores 100% on its training data but poorly on new data. This is called…

It memorised the training examples instead of learning the general pattern: overfitting.
