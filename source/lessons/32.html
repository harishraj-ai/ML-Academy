When labels are scarce

Data is often cheap and labels expensive. A hospital has millions of scans but few that a radiologist has annotated; a support team has thousands of tickets but only a few hundred tagged by topic; a factory records every product image but inspects only some. Two families of methods help:

  • Semi-supervised learning uses the unlabelled data as well as the labelled, assuming its structure carries information about the labels.
  • Active learning chooses which examples to send for labelling, so each label teaches the model as much as possible.

This lesson uses scikit-learn's handwritten digits (1,797 small 8×8 images of the digits 0–9), pretending only a few are labelled.

The core idea

Unlabelled points aren't useless: if similar points usually share a label, the unlabelled ones show where the classes lie. And not all labels are equally useful: one example near the boundary between classes teaches the model more than ten it already gets right.

The baseline: 50 labels

Hold out 30% of the images as a test set. Of the remaining 1,257 "pool" images, pretend only 50 random ones are labelled:

import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
X, y = load_digits(return_X_y=True)
X = StandardScaler().fit_transform(X)
X_pool, X_test, y_pool, y_test = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
rng = np.random.default_rng(0)
labelled = rng.choice(len(X_pool), 50, replace=False)            # only 50 of 1,257 images labelled
clf = LogisticRegression(max_iter=2000).fit(X_pool[labelled], y_pool[labelled])
full = LogisticRegression(max_iter=2000).fit(X_pool, y_pool)
print("labelled examples:", len(labelled), "of", len(X_pool))
print("accuracy with 50 labels:", round(clf.score(X_test, y_test), 3), "  with all labels:", round(full.score(X_test, y_test), 3))

Output:

labelled examples: 50 of 1257
accuracy with 50 labels: 0.811   with all labels: 0.972

With 50 labels, logistic regression reaches 81.1% test accuracy; with all 1,257 it reaches 97.2%. The question for this lesson: how much of that gap can we close without labelling everything?

Why unlabelled data can help

Semi-supervised methods rely on assumptions about how the data is arranged:

  • Smoothness: points close together tend to have the same label.
  • Cluster: points form clusters, and each cluster mostly has one label, so decision boundaries should pass through low-density gaps.
  • Manifold: high-dimensional data lies near a lower-dimensional surface (Lesson 17), along which labels change slowly.

When these hold, as they often do for images, text and sensor data, unlabelled points help draw the boundary. When they don't, semi-supervised learning can make things worse, so always compare with the labelled-only baseline.

Self-training with pseudo-labels

Self-training is the simplest approach: train on the labelled data, predict the unlabelled data, add the most confident predictions as pseudo-labels, retrain, and repeat. The confidence threshold controls the trade-off between adding more data and adding wrong labels:

from sklearn.semi_supervised import SelfTrainingClassifier
y_partial = np.full(len(y_pool), -1); y_partial[labelled] = y_pool[labelled]   # -1 means "unlabelled"
for thr in [0.99, 0.9, 0.6]:
    st = SelfTrainingClassifier(LogisticRegression(max_iter=2000), threshold=thr).fit(X_pool, y_partial)
    added = (st.labeled_iter_ > 0).sum()
    wrong = (st.transduction_[st.labeled_iter_ > 0] != y_pool[st.labeled_iter_ > 0]).mean()
    print(f"threshold {thr}: pseudo-labels added {added}, of which wrong {wrong:.1%}, test accuracy {st.score(X_test, y_test):.3f}")

Output:

threshold 0.99: pseudo-labels added 66, of which wrong 1.5%, test accuracy 0.819
threshold 0.9: pseudo-labels added 1008, of which wrong 5.8%, test accuracy 0.911
threshold 0.6: pseudo-labels added 1189, of which wrong 13.0%, test accuracy 0.872

At a threshold of 0.99, only 66 very safe pseudo-labels are added, and accuracy barely moves (81.9%). At 0.9, 1,008 are added with 5.8% wrong, and accuracy jumps to 91.1%. At 0.6, more wrong labels (13%) creep in and accuracy falls back to 87.2%: the model starts learning its own mistakes, a problem called confirmation bias. Tune the threshold on a labelled validation set.

Label spreading on a graph

Label propagation and label spreading build a graph connecting each point to its nearest neighbours, then let the known labels flow along the edges until they settle, so each unlabelled point takes the label of the region it's in. It's the smoothness assumption put directly into an algorithm:

from sklearn.semi_supervised import LabelSpreading
ls = LabelSpreading(kernel="knn", n_neighbors=7, alpha=0.2).fit(X_pool, y_partial)
spread_acc = (ls.transduction_ == y_pool).mean()
print("label spreading: share of pool labels inferred correctly", round(spread_acc, 3))
clf_ls = LogisticRegression(max_iter=2000).fit(X_pool, ls.transduction_)
print("logistic regression trained on the spread labels: test accuracy", round(clf_ls.score(X_test, y_test), 3))

Output:

label spreading: share of pool labels inferred correctly 0.876
logistic regression trained on the spread labels: test accuracy 0.881

From 50 labels, spreading infers the labels of 87.6% of the pool correctly. A classifier trained on those inferred labels reaches 88.1% test accuracy. Graph methods work well when neighbours in feature space really share labels, so they depend on a good distance measure and scaling (Lesson 11), and they get slow on very large datasets.

Active learning: choose what to label

If a person will label some examples, let the model pick which. Uncertainty sampling sends the examples the model is least sure about. Here, uncertainty is the margin between its top two class probabilities: a small margin means it's torn between two digits. We start with 20 random labels, then run 10 rounds of picking 15 more, either at random or by uncertainty:

def active_learning(strategy, rounds=10, batch=15, seed=0):
    r = np.random.default_rng(seed)
    lab = list(r.choice(len(X_pool), 20, replace=False))
    for _ in range(rounds):
        m = LogisticRegression(max_iter=2000).fit(X_pool[lab], y_pool[lab])
        rest = np.setdiff1d(np.arange(len(X_pool)), lab)
        if strategy == "uncertainty":
            P = np.sort(m.predict_proba(X_pool[rest]), axis=1)
            pick = rest[np.argsort(P[:, -1] - P[:, -2])[:batch]]    # smallest margin between the top two classes
        else:
            pick = r.choice(rest, batch, replace=False)
        lab += list(pick)
    return len(lab), LogisticRegression(max_iter=2000).fit(X_pool[lab], y_pool[lab]).score(X_test, y_test)
for strategy in ["random", "uncertainty"]:
    res = [active_learning(strategy, seed=s) for s in range(5)]
    print(f"{strategy:11s}: {res[0][0]} labels, mean test accuracy {np.mean([a for _, a in res]):.3f}")

Output:

random     : 170 labels, mean test accuracy 0.917
uncertainty: 170 labels, mean test accuracy 0.947
budgets = [50, 100, 200, 400]
for b in budgets:
    accs = []
    for s in range(3):
        idx = np.random.default_rng(s).choice(len(X_pool), b, replace=False)
        accs.append(LogisticRegression(max_iter=2000).fit(X_pool[idx], y_pool[idx]).score(X_test, y_test))
    print(f"{b} random labels: test accuracy {np.mean(accs):.3f}")

Output:

50 random labels: test accuracy 0.814
100 random labels: test accuracy 0.886
200 random labels: test accuracy 0.922
400 random labels: test accuracy 0.946

With the same 170 labels, uncertainty sampling reaches 94.7% accuracy against 91.7% for random labelling. Random labelling needs about 400 labels to reach that level, so active learning saved more than half the labelling effort here. The cost is a human in the loop every round, and a risk: uncertainty sampling can keep picking strange outliers or noisy examples. Practical systems mix in some random picks and choose diverse batches.

Choosing an approach

SituationTry
Lots of unlabelled data, clear clustersLabel spreading, or self-training with a high threshold
A labelling budget and someone availableActive learning (uncertainty sampling plus some random picks)
Labels can be produced roughly by rulesWeak supervision: combine several noisy labelling rules, then train on the result
Images or text with huge unlabelled setsSelf-supervised pretraining and fine-tuning (covered in deep learning courses)
A related task has many labelsTransfer learning: start from a model trained on that task

Whatever you choose, keep a properly labelled test set that the method never touches. It's tempting to evaluate on pseudo-labels, but those carry the model's own mistakes.

In Python: self-training by hand

The self-training loop in a few lines, so you can see exactly what happens each round: fit, predict the unlabelled points, and move the confident ones into the training set:

import numpy as np
from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

X, y = load_digits(return_X_y=True)
X_pool, X_test, y_pool, y_test = train_test_split(X / 16, y, test_size=0.3, random_state=1, stratify=y)
lab = np.random.default_rng(1).choice(len(X_pool), 60, replace=False)
Xl, yl = X_pool[lab], y_pool[lab]
Xu = np.delete(X_pool, lab, axis=0)
for rnd in range(1, 5):
    m = LogisticRegression(max_iter=3000).fit(Xl, yl)
    P = m.predict_proba(Xu)
    sure = P.max(axis=1) > 0.9
    print(f"round {rnd}: {len(yl)} training labels, test accuracy {m.score(X_test, y_test):.3f}, adding {sure.sum()} pseudo-labels")
    Xl, yl = np.vstack([Xl, Xu[sure]]), np.concatenate([yl, m.classes_[P[sure].argmax(axis=1)]])
    Xu = Xu[~sure]

Output:

round 1: 60 training labels, test accuracy 0.878, adding 14 pseudo-labels
round 2: 74 training labels, test accuracy 0.876, adding 32 pseudo-labels
round 3: 106 training labels, test accuracy 0.870, adding 47 pseudo-labels
round 4: 153 training labels, test accuracy 0.857, adding 36 pseudo-labels

Each round adds the confident predictions as labels and retrains. Here, with a different split and simpler scaling than earlier, self-training doesn't help: accuracy drifts down from 87.8% to 85.7%, because the confident pseudo-labels are mostly easy examples the model already handled, plus a few confident mistakes. That's a common real outcome, and exactly why you should always compare with the labelled-only baseline before trusting any semi-supervised method.

Key takeaways

  • Semi-supervised learning uses unlabelled data, relying on smoothness, cluster or manifold assumptions.
  • Self-training adds confident pseudo-labels; too low a threshold teaches the model its own mistakes.
  • Label spreading passes labels along a nearest-neighbour graph.
  • Active learning picks the most informative examples to label, often halving labelling cost.
  • Always compare with the labelled-only baseline on a truly labelled test set.
