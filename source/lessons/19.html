What makes learning "deep"?

Deep learning means neural networks with many layers. Each layer builds on the previous one: in an image network, early layers detect edges, middle layers combine edges into textures and shapes, and later layers recognise eyes, wheels or letters. The network learns this hierarchy of features by itself, from data.

Lesson 18's fully connected network treats every input independently. For images, sound and text that wastes structure we know is there — nearby pixels belong together; word order matters. Deep learning's big successes come from architectures built around that structure: convolutional networks for images, recurrent networks for sequences, and Transformers, which now power language models. This lesson explains how each works, plus the techniques that make deep networks trainable.

Making deep networks trainable

Vanishing gradients

Backpropagation multiplies derivatives layer by layer (Lesson 18). The sigmoid's derivative is at most $0.25$. Through 10 sigmoid layers, a gradient can shrink by a factor of up to $0.25^{10} \approx 0.000001$ — the early layers barely learn. This vanishing gradient problem held deep learning back for years. Fixes:

  • ReLU activations: derivative exactly 1 for positive inputs, so gradients pass through undiminished.
  • Careful initialisation: scale random initial weights to the layer size (e.g. "He" or "Glorot" initialisation) so signals neither explode nor vanish.
  • Normalisation layers (batch norm, layer norm): rescale each layer's activations to a stable range during training.
  • Residual (skip) connections: compute $\mathbf{h} + f(\mathbf{h})$ instead of $f(\mathbf{h})$, giving gradients a shortcut path. These made networks with 100+ layers possible.

Better optimisers

Momentum keeps a running average of past gradients, so steps build speed in consistent directions and damp oscillations — like a ball rolling downhill. Adam (Kingma & Ba, ICLR 2015) combines momentum with a per-parameter step size, adapted from running averages of the gradient $g$ and the squared gradient:

$$m \leftarrow \beta_1 m + (1-\beta_1)g, \qquad s \leftarrow \beta_2 s + (1-\beta_2)g^2, \qquad w \leftarrow w - \eta\,\frac{\hat{m}}{\sqrt{\hat{s}} + \epsilon}$$

($\hat{m}, \hat{s}$ are bias-corrected versions of $m, s$; typical values are $\beta_1 = 0.9$, $\beta_2 = 0.999$.) Parameters with consistently large gradients take smaller steps, and rarely-updated ones take larger steps. Adam is the default optimiser in most deep learning work.

Fighting overfitting

  • Dropout: during training, randomly switch off a fraction of neurons (e.g. 20–50%) at each step. No neuron can rely on any specific other neuron, which acts like training an ensemble of many thinner networks (Lesson 14).
  • Data augmentation: create extra training examples by flipping, cropping or slightly rotating images — the label stays the same.
  • Early stopping and weight decay (L2), as before.

Convolutional neural networks (CNNs)

A 224×224 colour image has $224\times224\times3 = 150{,}528$ inputs. A fully connected layer of just 1,000 neurons would need 150 million weights — and it would have to learn "cat ear" separately for every position in the image. CNNs fix this with two ideas:

  • Local connections: each neuron looks only at a small patch (e.g. 3×3 pixels).
  • Weight sharing: the same small set of weights — a filter or kernel — is slid across the whole image. A feature detector learned in one place works everywhere.

The convolution operation

Slide the kernel over the image. At each position, multiply the overlapping numbers element by element and add them up; that sum is one pixel of the output, called a feature map.

$$\text{out}[i, j] = \sum_{u}\sum_{v}\text{image}[i + u,\ j + v]\cdot\text{kernel}[u, v]$$
Worked example — detecting a vertical edge

A 4×6 image: dark (0) on the left, bright (9) on the right. A 3×3 vertical-edge kernel:

$$\text{image} = \begin{bmatrix}0&0&0&9&9&9\\0&0&0&9&9&9\\0&0&0&9&9&9\\0&0&0&9&9&9\end{bmatrix} \qquad \text{kernel} = \begin{bmatrix}-1&0&1\\-1&0&1\\-1&0&1\end{bmatrix}$$

The kernel computes (right column − left column) of each 3×3 window.

  • Window over columns 1–3 (all 0s): $0$.
  • Window over columns 2–4: left column 0s, right column 9s: $3\times9 - 0 = 27$.
  • Window over columns 3–5: left 0s, right 9s again: $27$.
  • Window over columns 4–6 (all 9s): $3\times9 - 3\times9 = 0$.
$$\text{feature map} = \begin{bmatrix}0 & 27 & 27 & 0\\ 0 & 27 & 27 & 0\end{bmatrix}$$

The output "lights up" exactly where the edge is and is 0 in flat regions. A CNN learns its kernel values by backpropagation, discovering whatever detectors are useful.

Output size, stride and padding

For input width $W$, kernel size $F$, padding $P$ (zeros added around the border) and stride $S$ (step size):

$$W_{\text{out}} = \frac{W - F + 2P}{S} + 1$$

Example above: $(6 - 3 + 0)/1 + 1 = 4$ ✓. With a 28×28 image, $F = 3$, $P = 1$, $S = 1$: $(28 - 3 + 2)/1 + 1 = 28$ — "same" padding keeps the size.

Channels and parameter counts

A colour image has 3 channels (red, green, blue), so a 3×3 kernel actually has $3\times3\times3 = 27$ weights plus a bias. A layer usually has many kernels, each producing its own feature map. 16 kernels: $(27 + 1)\times16 = 448$ parameters. Compare a fully connected layer from a 32×32×3 image to just 16 neurons: $3072\times16 + 16 = 49{,}168$. Weight sharing makes CNNs over 100 times leaner here.

Pooling

Max pooling shrinks a feature map by keeping only the largest value in each small window, usually 2×2 with stride 2. It keeps "was the feature present around here?" while discarding the exact position, and cuts the size by 4×, which discards 75% of the activations.

Worked example — 2×2 max pooling
$$\begin{bmatrix}1&3&2&0\\4&6&1&1\\0&2&5&7\\1&1&3&2\end{bmatrix} \xrightarrow{\ \text{max pool}\ } \begin{bmatrix}6 & 2\\ 2 & 7\end{bmatrix}$$

Top-left window $\{1, 3, 4, 6\}$ → 6; top-right $\{2, 0, 1, 1\}$ → 2; bottom-left $\{0, 2, 1, 1\}$ → 2; bottom-right $\{5, 7, 3, 2\}$ → 7.

A typical CNN

[conv → ReLU → pool] repeated several times (feature maps get smaller but more numerous), then flatten, then one or two fully connected layers, then softmax over the classes.

Recurrent neural networks (RNNs)

Text, speech, sensor readings and prices are sequences: order matters, and lengths vary. An RNN reads a sequence one step at a time, carrying a hidden state $\mathbf{h}_t$ — a memory of what it has seen so far:

$$\mathbf{h}_t = \tanh\big(W_h\mathbf{h}_{t-1} + W_x\mathbf{x}_t + \mathbf{b}\big)$$

The same weights are used at every step (weight sharing again, this time across time). The final state, or the state at each step, feeds an output layer — e.g. to classify a review as positive or negative, or to predict the next word.

The problem: training backpropagates through every time step, multiplying by $W_h$ again and again, so gradients vanish (or explode) over long sequences. Plain RNNs struggle to remember things from more than about 10–20 steps back.

LSTMs

The long short-term memory network (Hochreiter & Schmidhuber, 1997) adds a separate cell state — a kind of conveyor belt that information can travel along unchanged — controlled by three gates. Each gate is a sigmoid layer outputting numbers between 0 and 1, multiplied element-wise with the information it controls:

  • the forget gate decides what to erase from the cell state;
  • the input gate decides what new information to write;
  • the output gate decides what part of the cell state to output as $\mathbf{h}_t$.

Because the cell state is updated by addition rather than repeated multiplication, gradients survive over much longer sequences. LSTMs (and the simpler GRUs) dominated sequence tasks until Transformers arrived.

Transformers and attention

RNNs process words one at a time, which is slow and makes long-range connections hard. The Transformer (Vaswani et al., 2017, "Attention Is All You Need") is "based solely on attention mechanisms, dispensing with recurrence and convolutions entirely". Every position looks at every other position directly, in one step.

Self-attention

Each word (token) is represented by a vector. From it, the model computes three vectors with learned weight matrices:

  • a query $\mathbf{q}$ — "what am I looking for?",
  • a key $\mathbf{k}$ — "what do I contain?",
  • a value $\mathbf{v}$ — "what do I pass on if selected?".

Each token compares its query with every token's key (dot products — Lesson 2 — measure similarity), turns the scores into weights with softmax (Lesson 8), and takes the weighted average of the values:

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Dividing by $\sqrt{d_k}$ (the key length) keeps the scores from growing too large as vectors get longer.

Worked example — attention over three tokens

Three tokens with 2-dimensional vectors. For simplicity, queries = keys: $\mathbf{q}_1 = \mathbf{k}_1 = (1, 0)$, $\mathbf{q}_2 = \mathbf{k}_2 = (0, 1)$, $\mathbf{q}_3 = \mathbf{k}_3 = (1, 1)$. Values: $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 1)$, $\mathbf{v}_3 = (0.5, 0.5)$. Here $d_k = 2$, so we divide by $\sqrt2 \approx 1.414$.

Token 1's scores against keys 1, 2, 3: $\frac{(1,0)\cdot(1,0)}{\sqrt2} = 0.707$, $\ \frac{(1,0)\cdot(0,1)}{\sqrt2} = 0$, $\ \frac{(1,0)\cdot(1,1)}{\sqrt2} = 0.707$.

Softmax: $e^{0.707} \approx 2.03$, $e^0 = 1$, $e^{0.707} \approx 2.03$; total $5.06$. Weights $\approx (0.401,\ 0.198,\ 0.401)$.

Output: $0.401\,(1, 0) + 0.198\,(0, 1) + 0.401\,(0.5, 0.5) \approx (0.602,\ 0.398)$.

Token 1 "attended" most to itself and to token 3, whose keys resemble its query, and its new representation mixes in their values. In a sentence like "The animal didn't cross the street because it was tired", attention lets "it" pull information from "animal".

A Transformer stacks many such layers, each with several attention "heads" running in parallel, plus small feed-forward networks, residual connections and layer normalisation. Since attention itself ignores order, a positional encoding is added to each token's vector. Because all positions are processed at once, Transformers train efficiently on GPUs — which is what made today's large language models possible.

Transfer learning: standing on giants' shoulders

Training a large network from scratch needs huge datasets and computing power. Instead, you can take a pretrained model — trained on millions of images or billions of words — and fine-tune it on your smaller dataset. Its early layers already detect general features (edges, word meanings), so you only need to adapt the later layers. This is how most practical deep learning is done today.

Tools

scikit-learn's MLPClassifier is fine for small fully connected networks (Lesson 18), but it has no convolutions, recurrence, attention or GPU support. For deep learning, practitioners use PyTorch or TensorFlow/Keras, which compute gradients automatically ("autograd") and run on GPUs.

In Python

Convolution, pooling and attention from scratch with NumPy — the same calculations as the worked examples:

import numpy as np

def conv2d(image, kernel):
    kh, kw = kernel.shape
    out = np.zeros((image.shape[0] - kh + 1, image.shape[1] - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = np.sum(image[i:i+kh, j:j+kw] * kernel)
    return out

image = np.array([[0, 0, 0, 9, 9, 9]] * 4, dtype=float)
edge = np.array([[-1, 0, 1]] * 3, dtype=float)
print(conv2d(image, edge))

fmap = np.array([[1, 3, 2, 0], [4, 6, 1, 1], [0, 2, 5, 7], [1, 1, 3, 2]], dtype=float)
print(fmap.reshape(2, 2, 2, 2).max(axis=(1, 3)))      # 2x2 max pooling

def attention(Q, K, V):
    scores = Q @ K.T / np.sqrt(K.shape[1])
    weights = np.exp(scores) / np.exp(scores).sum(axis=1, keepdims=True)   # softmax per row
    return weights, weights @ V

Q = K = np.array([[1, 0], [0, 1], [1, 1]], dtype=float)
V = np.array([[1, 0], [0, 1], [0.5, 0.5]])
weights, out = attention(Q, K, V)
print(weights.round(3))
print(out.round(3))

Every number matches the worked examples. For reference, this is what a small CNN for 28×28 grayscale digits looks like in PyTorch. This snippet was not run as part of this course's checks — PyTorch must be installed separately (see pytorch.org).

import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(1, 16, kernel_size=3, padding=1),   # 28x28x1  -> 28x28x16
    nn.ReLU(),
    nn.MaxPool2d(2),                              # -> 14x14x16
    nn.Conv2d(16, 32, kernel_size=3, padding=1),  # -> 14x14x32
    nn.ReLU(),
    nn.MaxPool2d(2),                              # -> 7x7x32
    nn.Flatten(),                                 # -> 1568 numbers
    nn.Dropout(0.25),
    nn.Linear(32 * 7 * 7, 10),                    # one score per digit
)

Key takeaways

  • Deep networks learn a hierarchy of features. ReLU, good initialisation, normalisation and residual connections fight vanishing gradients; Adam and dropout help training and generalization.
  • CNNs slide small shared kernels over images: output size $(W - F + 2P)/S + 1$; pooling downsamples.
  • RNNs carry a hidden state through a sequence; LSTMs use gates and a cell state to remember longer.
  • Transformers use self-attention, $\text{softmax}(QK^\top/\sqrt{d_k})V$, so every token can look at every other token at once.
  • In practice, start from a pretrained model and fine-tune it.
