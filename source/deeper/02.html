Going deeper: the linear algebra behind ML algorithms

Intermediate · skip on a first read

The lesson above gives you what you need to use vectors and matrices in ML code. This section covers the ideas that explain why algorithms behave as they do: why lasso and ridge give different weights, why some regressions can't be solved, how PCA and recommender systems find hidden structure, and why nearly duplicate features make a model unstable. Each idea is used again in a later lesson, which is named as you go.

You'll need: everything in this lesson, especially the dot product, matrix × matrix and the transpose.

Other ways to measure size: norms

Section 4 measured a vector's length with the familiar straight-line distance. That's one norm, a rule that gives every vector a size. ML uses several, and the choice changes how models behave:

  • L2 norm $\lVert\mathbf{v}\rVert_2 = \sqrt{v_1^2 + \dots + v_n^2}$: the straight-line length. Big entries count a lot, because they're squared.
  • L1 norm $\lVert\mathbf{v}\rVert_1 = |v_1| + \dots + |v_n|$: the "city-block" distance, as if you could only walk along streets. Every entry counts in proportion to its size.
  • L∞ norm $\lVert\mathbf{v}\rVert_\infty = \max_i |v_i|$: only the biggest entry counts.
  • Frobenius norm of a matrix, $\lVert A\rVert_F = \sqrt{\sum_{i,j} a_{ij}^2}$: the L2 norm of all its entries treated as one long list. It measures how far apart two matrices are, as in the SVD example below.

For $\mathbf{v} = (3, -4, 1)$: L1 is $3 + 4 + 1 = 8$, L2 is $\sqrt{9 + 16 + 1} = \sqrt{26} \approx 5.099$, and L∞ is $4$. Why it matters: ridge regression (Lesson 10) penalises the L2 norm of the weights and shrinks them all a little; lasso penalises the L1 norm and pushes some exactly to zero. The difference comes from the shapes of the "unit balls" $\lVert\mathbf{v}\rVert = 1$: a circle for L2, but a diamond with sharp corners on the axes for L1. kNN (Lesson 11) can use L1 or L2 distance too.

Independence, rank and the determinant

Columns of a matrix are linearly independent if none of them can be built from the others by adding and scaling. The rank is the number of independent columns. It matters because least squares needs $X^\top X$ to be invertible, and that happens only when the columns of $X$ are independent (full rank).

The determinant of a square matrix is the factor by which it scales areas (in 2D) or volumes (in 3D). If $\det A = 0$, the matrix squashes space flat, information is lost, and $A$ has no inverse.

The third feature is exactly feature 1 + feature 2, so only 2 of the 3 columns carry new information: rank 2, and $\det(X^\top X) = 0$. This is the same problem as the dummy-variable trap in Lesson 6. For the 2×2 matrix $A$, $\det A = 2\cdot 3 - 1\cdot 1 = 5$: it stretches every shape to 5 times its area.

Eigenvalues and eigenvectors

Most vectors change direction when you multiply them by a matrix. An eigenvector is a special direction that the matrix only stretches or shrinks:

$$A\mathbf{v} = \lambda\mathbf{v}$$

The number $\lambda$ is its eigenvalue: how much that direction is stretched. To find the eigenvalues by hand, solve $\det(A - \lambda I) = 0$. For $A = \begin{pmatrix}2 & 1\\ 1 & 3\end{pmatrix}$:

$$\det\begin{pmatrix}2-\lambda & 1\\ 1 & 3-\lambda\end{pmatrix} = (2-\lambda)(3-\lambda) - 1 = \lambda^2 - 5\lambda + 5 = 0 \;\Rightarrow\; \lambda = \frac{5 \pm \sqrt{5}}{2} \approx 1.382,\ 3.618$$

For $\lambda = 3.618$, the first row of $(A - \lambda I)\mathbf{v} = 0$ gives $v_2 = 1.618\,v_1$; scaled to length 1, that's $\mathbf{v} \approx (0.526, 0.851)$.

The check $A\mathbf{v} = \lambda\mathbf{v}$ works, and the two eigenvectors have dot product 0: they're at right angles. That's not luck. The spectral theorem says every symmetric matrix ($A = A^\top$) has real eigenvalues and a full set of perpendicular eigenvectors, so it can be written as $A = Q\Lambda Q^\top$ (rotate, stretch along the axes, rotate back). Covariance matrices are symmetric, which is exactly why PCA (Lesson 17) works: its components are the covariance matrix's eigenvectors, and each eigenvalue is the variance along that direction. Use np.linalg.eigh for symmetric matrices; it's faster and more accurate than the general eig.

Positive definite matrices

A symmetric matrix is positive definite if $\mathbf{x}^\top A\mathbf{x} > 0$ for every non-zero $\mathbf{x}$, which is the same as all its eigenvalues being positive. It's positive semi-definite (PSD) if $\ge 0$ is allowed. The matrix $A$ above is positive definite: both eigenvalues are positive.

The matrix that appears all over ML, $X^\top X$, is always PSD, and the proof is one line:

$$\mathbf{w}^\top (X^\top X)\,\mathbf{w} = (X\mathbf{w})^\top(X\mathbf{w}) = \lVert X\mathbf{w}\rVert^2 \ge 0$$

It's positive definite exactly when the columns of $X$ are independent. Lesson 3's "Going deeper" uses this to show that the squared-error loss is convex: shaped like a bowl, with one lowest point.

The singular value decomposition (SVD)

Eigenvectors need a square matrix. The SVD works for any matrix, including a data table with $n$ rows and $d$ columns:

$$A = U\,\Sigma\,V^\top$$

$U$ and $V$ have perpendicular columns (directions in row space and column space), and $\Sigma$ is diagonal with the singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$, which say how important each direction is. The key result (the Eckart–Young theorem) is that keeping only the $k$ largest singular values gives the best possible rank-$k$ approximation of $A$.

The singular values drop sharply after the third (38.5, then 3.9): the SVD has discovered that 3 hidden factors explain the table. A rank-3 approximation stores 273 numbers instead of 2,000, with a relative error of 0.157, and most of that error is the random noise. Keeping more singular values hardly helps (0.142 at rank 5), because they only describe noise. This is the idea behind recommender systems (predicting missing ratings), PCA (Lesson 17, which is the SVD of the centred data), image compression and the pseudo-inverse $A^{+} = V\Sigma^{+}U^\top$ that np.linalg.lstsq uses to solve least squares safely.

Condition number: when tiny changes cause big swings

The condition number of a matrix is the ratio of its largest to its smallest singular value (for a symmetric PSD matrix like $X^\top X$, its largest to smallest eigenvalue). It measures how much small errors in the input can be amplified in the answer. A value near 1 is perfect; values in the thousands or millions mean trouble. In this example, two features measure almost the same thing: a home's size, recorded twice with slightly different tape measures.

With a condition number of about 14,000, a tiny change in $y$ swings the weights from $(0.96, -0.36)$ to $(1.2, -0.61)$. Their sum stays near 0.6, so the predictions barely change, but the individual weights mean nothing. This is the linear-algebra view of multicollinearity (Lesson 6's "Going deeper"). Adding $\lambda I$, which is exactly what ridge regression does, raises every eigenvalue by $\lambda$. That cuts the condition number about tenfold, to 1,462, and the weights become stable ($0.37, 0.23$ and then $0.39, 0.21$).

Matrix calculus: the four rules you'll actually use

Many ML derivations need the gradient of an expression with vectors and matrices in it. These rules cover almost all of them ($\mathbf{a}$ is a constant vector and $A$ a constant matrix):

Function of $\mathbf{w}$Gradient $\nabla_{\mathbf{w}}$Like the 1-D rule
$\mathbf{a}^\top\mathbf{w}$$\mathbf{a}$$\frac{d}{dw}(aw) = a$
$\mathbf{w}^\top\mathbf{w} = \lVert\mathbf{w}\rVert^2$$2\mathbf{w}$$\frac{d}{dw}w^2 = 2w$
$\mathbf{w}^\top A\,\mathbf{w}$$(A + A^\top)\,\mathbf{w}$, which is $2A\mathbf{w}$ if $A$ is symmetric$\frac{d}{dw}aw^2 = 2aw$
$\lVert X\mathbf{w} - \mathbf{y}\rVert^2$$2X^\top(X\mathbf{w} - \mathbf{y})$chain rule
