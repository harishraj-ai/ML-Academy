Going deeper: when features are correlated

Intermediate · skip on a first read

Almost every real dataset has correlated features, and that's where explanation methods disagree most. This section puts two near-identical features into a model and compares how permutation importance, drop-column importance and SHAP share the credit, then shows the exact SHAP formula for linear models and how SHAP values become a global ranking.

You'll need: this lesson, and multicollinearity from Lesson 6's "Going deeper".

Three methods, three answers

Here the target depends on a (weight 3) and c (weight 1). Feature b is a near-copy of a that adds nothing new. Drop-column importance retrains the model without each feature and measures the loss; it answers "what would we lose if we didn't have this feature at all?"

Permutation importance says a matters most (1.045) and gives b some credit (0.129), because the forest happens to split on both. Drop-column importance says neither a nor b matters much (0.004 and 0): remove one and the model simply uses the other. Only c, which carries unique information, loses a lot when dropped (0.117). Neither answer is wrong: permutation asks "does this model use the feature?", drop-column asks "is the information replaceable?". When features are correlated, report them as a group, or shuffle or drop the whole group together.

Exact SHAP for linear models, and global SHAP

For a linear model $f(\mathbf{x}) = b + \sum_j w_jx_j$ with independent features, the Shapley value has a closed form: $\phi_j = w_j\,(x_j - \bar{x}_j)$, the weight times how far this row's value is from the average. The linear model split the effect of the near-duplicates as 2.75 for a and 0.24 for b; with different random noise the split could easily come out differently (Lesson 6's "Going deeper" on unstable weights). The mean absolute SHAP values (2.31, 0.20, 0.79) inherit that arbitrary split. And the efficiency check holds: baseline plus contributions equals the prediction exactly (3.9815). Two ways to explain with correlated features: interventional SHAP (the default in most tools) treats features as independent and explains the model; conditional SHAP respects the correlations and explains the data-generating relationship more, but is harder to compute and can give credit to features the model never uses.
