14.Going deeper: attention and residual connections, from scratch

In plain wordsThe two ideas behind transformers, built from scratch: attention (each word decides which other words to listen to) and residual connections (a shortcut that lets very deep networks learn), plus word order and how to reuse pretrained models cheaply.

Intermediate · skip on a first read

Attention, step by step

Picture it

At a noisy party you can't listen to everyone equally. You tune in to the people talking about what you care about. In attention, each word has a question (query); every word wears a label (key); a word listens most to those whose labels match its question, and takes in what they say (their values).

Three learned matrices turn each token into a query, a key and a value. Each token's output is a weighted average of all the values, with weights from how well its query matches each key:

$$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Piece by piece: $QK^\top$ = every query dotted with every key (match scores); divide by $\sqrt{d_k}$ (explained next); softmax turns each row into weights adding to 1; multiply by $V$ = take that weighted mix of values.

Worked example — one token, three keys
  1. Match scores (after scaling): 2, 1, 0.
  2. $e^2, e^1, e^0 = 7.39, 2.72, 1.00$; total 11.11.
  3. Weights: $0.67, 0.24, 0.09$ (they add to 1).
  4. Output $=0.67\,v_1+0.24\,v_2+0.09\,v_3$: mostly token 1's information.
import numpy as np

# Scaled dot-product attention from scratch, for a "sentence" of 4 tokens with 8-number vectors
rng = np.random.default_rng(0)
X = rng.normal(size=(4, 8))                                    # one row per token
Wq, Wk, Wv = (rng.normal(0, 1 / np.sqrt(8), size=(8, 8)) for _ in range(3))
Q, K, V = X @ Wq, X @ Wk, X @ Wv

def softmax(s):
    e = np.exp(s - s.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

A = softmax(Q @ K.T / np.sqrt(8))                              # attention weights, one row per token
out = A @ V                                                    # each output mixes the value vectors
print("attention weights (row i: how much token i looks at each token):")
print(A.round(2))
print("each row sums to:", A.sum(axis=1).round(3), "  output shape:", out.shape)

Output:

attention weights (row i: how much token i looks at each token):
[[0.34 0.13 0.33 0.2 ]
 [0.78 0.   0.05 0.17]
 [0.25 0.28 0.29 0.18]
 [0.22 0.28 0.21 0.29]]
each row sums to: [1. 1. 1. 1.]   output shape: (4, 8)

How to read it: row $i$ shows how much token $i$ attends to each token; each row adds to 1. Token 2 puts 78% on token 1; token 3 spreads its attention almost evenly. All tokens are computed at once with matrix products, which is why transformers train far faster on GPUs than RNNs, which go one step at a time. Multi-head attention runs several attentions in parallel with different matrices (one might track grammar, another meaning) and joins their outputs.

Why divide by $\sqrt{d_k}$, measured

Picture it

Longer vectors give bigger dot products, just as adding more numbers gives a bigger total. Very big scores make softmax put nearly all weight on one item, and then its slope is almost zero, so learning stalls. Dividing by $\sqrt{d}$ calms the scores back down.

Worked example — the size effect
  1. Entries with variance 1, $d=64$ dimensions: dot products have variance 64, so spread $\sqrt{64}=8$.
  2. Scores like 8 vs 0 give softmax weights of about $e^8/(e^8+1)\approx0.9997$: one-hot.
  3. Divide by 8: spread back to about 1, a soft, trainable mix.

Each query is compared with 10 random keys:

# Why divide by sqrt(d)? Dot products of random vectors grow with d, making softmax nearly one-hot
for d in [8, 64, 512]:
    q, k = rng.normal(size=(1000, d)), rng.normal(size=(1000, 10, d))
    raw = np.einsum("nd,nkd->nk", q, k)
    top_raw = softmax(raw).max(axis=1).mean()
    top_scaled = softmax(raw / np.sqrt(d)).max(axis=1).mean()
    print(f"d {d:3d}: spread of dot products {raw.std():6.1f}   average top weight, unscaled {top_raw:.2f}, scaled {top_scaled:.2f}")

Output:

d   8: spread of dot products    2.9   average top weight, unscaled 0.62, scaled 0.31
d  64: spread of dot products    8.0   average top weight, unscaled 0.85, scaled 0.31
d 512: spread of dot products   22.5   average top weight, unscaled 0.95, scaled 0.32

How to read it: unscaled, the average top weight climbs from 0.62 ($d=8$) to 0.95 ($d=512$): nearly every query locks onto one key. Scaled, it stays about 0.31 at every size.

Residual connections

Picture it

Instead of rewriting the whole essay at each draft, each editor only adds corrections in the margin. The original text always gets through, so even after 50 editors it's still readable. A residual block works the same way, and so does the learning signal flowing backwards.

A residual block computes $\mathbf{h} + f(\mathbf{h})$ instead of $f(\mathbf{h})$: the layer learns a correction. Backwards, its derivative is $I + J_f$: there is always a "1" path for the gradient, however small $J_f$ gets (the chain rule multiplies these, Lesson 3's Going deeper).

Worked example — why the "+1" saves the gradient
  1. Plain: each of 50 layers multiplies the gradient by about 0.5: $0.5^{50}\approx9\times10^{-16}$.
  2. Residual: each layer multiplies by about $1+( ext{something small})$, so the product stays around 1 or above instead of collapsing to zero.

A 50-layer tanh network with small weights, with and without shortcuts:

# Residual connections: gradient reaching the first of 50 layers, with and without a shortcut h + f(h)
def first_layer_grad(residual, depth=50, width=64):
    W = [rng.normal(0, 0.5 / np.sqrt(width), size=(width, width)) for _ in range(depth)]   # small weights
    h = rng.normal(size=(32, width)); zs = []
    for Wl in W:
        z = h @ Wl; zs.append(z)
        h = h + np.tanh(z) if residual else np.tanh(z)
    g = np.ones_like(h)
    for Wl, z in zip(reversed(W), reversed(zs)):
        local = (g * (1 - np.tanh(z) ** 2)) @ Wl.T              # gradient through the layer itself
        g = g + local if residual else local                    # the shortcut adds an identity path
    return np.linalg.norm(g)

print("plain 50-layer network, gradient at layer 1:   ", f"{first_layer_grad(False):.2e}")
print("residual 50-layer network, gradient at layer 1:", f"{first_layer_grad(True):.2e}")

Output:

plain 50-layer network, gradient at layer 1:    2.04e-14
residual 50-layer network, gradient at layer 1: 4.02e+02

How to read it: without shortcuts the first layer gets $2\times10^{-14}$, effectively zero; with them, about 400. ResNets (2015) used this to train image networks with over 100 layers, and every transformer block wraps its attention and its feed-forward part in a residual connection, usually with layer normalisation (Lesson 18's Going deeper).

Positions, and putting a transformer block together

Picture it

Attention alone sees a bag of words: "dog bites man" and "man bites dog" look identical. Adding a position signal to each word, like a seat number, puts the order back.

Positional encodings are added to the token vectors. The original transformer used sine and cosine waves of different speeds, $PE_{(p, 2i)} = \sin(p/10000^{2i/d})$, so every position gets a unique pattern; many modern LLMs use rotary encodings (RoPE), which rotate queries and keys by a position-dependent angle. One transformer block is:

  1. Multi-head self-attention, plus a residual connection, then layer norm.
  2. A small feed-forward network applied to each token separately (two layers, usually GELU), plus a residual connection, then layer norm.

A language model stacks dozens of these, uses a causal mask so each token can only look at earlier tokens, and is trained to predict the next token.

Transfer learning and fine-tuning

Picture it

A doctor who already knows anatomy learns a new speciality far faster than someone starting from zero. A pretrained model already knows edges and shapes, or grammar and facts; you only teach it the last part.

Training a large model from scratch needs huge data and compute. Instead, start from a model pretrained on a broad task and adapt it:

ApproachWhat's trainedWhen to use it
Feature extractionOnly a new output layer; the pretrained network is frozenVery little data; a task close to the pretraining task
Fine-tuningAll or the top layers, with a small learning rateA moderate amount of data; the best accuracy
Parameter-efficient fine-tuning (LoRA, adapters)Small added matrices; the original weights are frozenLarge language models: much less memory and storage per task
Prompting / in-context learningNothingLLMs, when instructions and a few examples are enough

LoRA uses an idea from Lesson 2's Going deeper: it learns the change to a big weight matrix as two thin matrices multiplied, $\Delta W = BA$, with a small rank $r$ (8 or 16).

Worked example — how much LoRA saves
  1. A $4096\times4096$ layer has $4096^2\approx16.8$ million weights.
  2. LoRA with $r=8$: $B$ is $4096\times8$, $A$ is $8\times4096$: $2\times4096\times8=65{,}536$ new numbers.
  3. About 256× fewer to train and store.
In one breath

Attention lets each token mix in information from the tokens whose keys match its query, with scores divided by $\sqrt{d}$ so softmax stays soft; residual connections give gradients a direct path through deep stacks; positional encodings restore word order; and fine-tuning a pretrained model (cheaply, with LoRA) beats training from scratch.

Interview corner · intermediate

Hidden questions — answer in your head first, then open.

Walk me through what a single self-attention head computes.

The trap: Describing attention as "focusing" without the computation.

Project each token's vector into a query, key and value with learned matrices. Compute scores $QK^\top$, scale by $1/\sqrt{d_k}$, apply a mask if needed (causal masking for language models), and softmax each row into weights. Each output is the weighted sum of the value vectors. Cost is quadratic in sequence length, which is why long contexts are expensive and why efficient-attention variants exist.

Why are residual connections so important in deep networks?

The trap: "They add information from earlier layers."

They make each block learn a correction $f(\mathbf{h})$ to an identity mapping. In backprop the Jacobian becomes $I + J_f$, so gradients always have a direct path to early layers, avoiding vanishing gradients through many layers. They also make very deep networks easy to optimise, since a block can default to doing almost nothing. Both ResNets and transformers depend on them.

What's LoRA, and why is it popular for fine-tuning LLMs?

The trap: Calling it a type of quantization.

Low-Rank Adaptation freezes the pretrained weights and learns, for chosen layers, a low-rank update $\Delta W = BA$ (rank 4–64). That trains and stores a tiny fraction of the parameters, needs much less GPU memory, and lets you keep many task-specific adapters for one base model. Quality is often close to full fine-tuning. QLoRA combines it with a quantized base model to save more memory.

Check your understanding: going deeper

1. In attention, what does each row of $\operatorname{softmax}(QK^\top/\sqrt{d})$ add up to?

Each row is a softmax: a set of weights for averaging the value vectors.

2. Without the $\sqrt{d}$ scaling, large $d$ makes the attention weights…

Dot-product spread grows like $\sqrt{d}$, pushing the softmax towards a single winner.

3. Why do residual connections help gradients flow?

Even if $f$'s Jacobian is tiny, the identity path carries the gradient back.

4. Without positional encodings, a transformer would treat a sentence as…

Self-attention is permutation-equivariant: it has no built-in notion of order.

5. LoRA fine-tunes a large model by…

$\Delta W = BA$ with a small rank, which is far fewer numbers to train and store.
