New words for this section
  • Label spreading: passing known labels along to nearby unlabelled points.
  • Feature scale: how big a feature's numbers are (centimetres vs kilometres).
  • Committee: several models trained on different resamples of the labelled data.
  • Baseline: a model trained on the labelled data only.

A wrong distance breaks label spreading

Picture it

Asking neighbours for directions only helps if "neighbour" means someone who knows the area. If you choose neighbours by the colour of their car instead of where they live, their advice is useless. Label spreading is only as good as its notion of "near".

The label depends only on feature 1, but feature 2 is irrelevant noise on a scale 50 times larger:

import numpy as np
from sklearn.semi_supervised import LabelSpreading
from sklearn.linear_model import LogisticRegression
rng = np.random.default_rng(0)
# The label depends on feature 1; feature 2 is irrelevant noise on a scale 50 times larger.
X = np.c_[rng.normal(0, 1, 600), rng.normal(0, 50, 600)]
y = (X[:, 0] > 0).astype(int)
lab = rng.choice(600, 20, replace=False)
yp = np.full(600, -1); yp[lab] = y[lab]
test = np.setdiff1d(np.arange(600), lab)
sup = LogisticRegression().fit(X[lab], y[lab]).score(X[test], y[test])
spread = (LabelSpreading(kernel="knn", n_neighbors=10).fit(X, yp).transduction_[test] == y[test]).mean()
Xs = X / X.std(axis=0)
spread_s = (LabelSpreading(kernel="knn", n_neighbors=10).fit(Xs, yp).transduction_[test] == y[test]).mean()
print("labelled only:", round(sup, 3), "  label spreading, raw features:", round(spread, 3), "  after scaling:", round(spread_s, 3))

Output:

labelled only: 0.919   label spreading, raw features: 0.557   after scaling: 0.864
Worked example — reading the three numbers
  1. Logistic regression on 20 labels: 91.9%. It learns to ignore feature 2.
  2. Label spreading, raw features: 55.7%, near guessing. Neighbours are chosen by the noise.
  3. After scaling: 86.4%. Better, but feature 2 still adds noise to every distance.

Unlabelled data helps only when the geometry matches how the labels change. Scale features, choose them carefully, and always compare with the labelled-only baseline.

Query-by-committee

Picture it

Ask a panel of judges about every case, and call in the expensive expert only for the cases where the judges argue the most. Those are the cases the expert's answer will teach the most.

Train a committee of models on bootstrap samples of the labelled data, and ask a person to label the points they disagree on most.

Worked example — measuring disagreement
  1. 5 models vote on an image: "3, 3, 3, 3, 3" → full agreement; skip it.
  2. Another image: "3, 8, 8, 3, 5" → strong disagreement; send it for labelling.

A committee of 5 logistic regressions picks 15 digits per round, compared with random picks:

from sklearn.datasets import load_digits
from sklearn.ensemble import BaggingClassifier
Xd, yd = load_digits(return_X_y=True); Xd = Xd / 16
pool, test2 = np.arange(1200), np.arange(1200, len(yd))
def run(strategy, seed):
    r = np.random.default_rng(seed); lab = list(r.choice(pool, 20, replace=False))
    for _ in range(10):
        rest = np.setdiff1d(pool, lab)
        if strategy == "committee":
            com = BaggingClassifier(LogisticRegression(max_iter=1000), n_estimators=5, random_state=seed).fit(Xd[lab], yd[lab])
            votes = np.array([est.predict(Xd[rest]) for est in com.estimators_])
            disagree = np.array([len(set(v)) for v in votes.T])           # number of distinct votes
            pick = rest[np.argsort(-disagree + 1e-3 * r.random(len(rest)))[:15]]
        else:
            pick = r.choice(rest, 15, replace=False)
        lab += list(pick)
    return LogisticRegression(max_iter=1000).fit(Xd[lab], yd[lab]).score(Xd[test2], yd[test2])
for s in ["random", "committee"]:
    print(f"{s:9s}: test accuracy with 170 labels {np.mean([run(s, k) for k in range(3)]):.3f}")

Output:

random   : test accuracy with 170 labels 0.883
committee: test accuracy with 170 labels 0.886

How to read it: with 170 labels, committee picks (88.6%) barely beat random picks (88.3%). On easy, well-separated digits random samples already cover every class, and the 5 models often agree. Active learning pays off most with imbalanced classes or complex boundaries, so measure its gain on a pilot before committing the labelling budget.

In one breath

Unlabelled data helps only when distances reflect how labels change, so scale and choose features and compare with a labelled-only baseline; query-by-committee sends for labelling the cases the models disagree on most, which helps most on hard, imbalanced problems.

Hidden questions — answer in your head first, then open.

When can semi-supervised learning hurt performance?

The trap: "Never; more data always helps."

When its assumptions fail: if nearby points (under the chosen distance) don't share labels, if the classes overlap in dense regions, or if the unlabelled data comes from a different distribution than the labelled data. Bad feature scaling or irrelevant features make this common. Compare with the labelled-only baseline on a properly labelled validation set and drop the method if it doesn't help.
