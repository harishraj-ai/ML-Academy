New words for this section
  • Prior: belief before seeing the data.
  • Posterior mean: the average of the updated belief.
  • MCMC chain: a sequence of random samples that wanders over the posterior.
  • Converged: the chain has forgotten where it started and samples the right distribution.
  • $\hat{R}$ (R-hat): compares several chains; close to 1.00 means they agree.

How much does the prior matter?

Picture it

Three people with different opinions read the same growing pile of evidence. After a page, they still disagree. After a whole book, they agree. If the answer still depends on who's reading, you need more evidence.

A Beta($a$, $b$) prior acts like $a$ conversions among $a+b$ earlier, imaginary visitors. Three analysts: flat Beta(1, 1); sceptical Beta(10, 190), centred on 5%; optimistic Beta(30, 170), centred on 15%. All see a 6% conversion rate:

Worked example — posterior means with 50 visitors (3 converted)
  1. Flat: $(1+3)/(2+50)\approx0.077$.
  2. Sceptical: $(10+3)/(200+50)=0.052$.
  3. Optimistic: $(30+3)/(200+50)=0.132$.
  4. The priors still dominate: 50 real visitors vs 200 imaginary ones.
from scipy import stats
for visitors, conv in [(50, 3), (500, 30), (5000, 300)]:
    row = []
    for name, a, b in [("flat", 1, 1), ("sceptical", 10, 190), ("optimistic", 30, 170)]:
        post = stats.beta(a + conv, b + visitors - conv)
        row.append(f"{name} {post.mean():.3f}")
    print(f"{visitors:5d} visitors (6% converted):", "   ".join(row))

Output:

   50 visitors (6% converted): flat 0.077   sceptical 0.052   optimistic 0.132
  500 visitors (6% converted): flat 0.062   sceptical 0.057   optimistic 0.086
 5000 visitors (6% converted): flat 0.060   sceptical 0.060   optimistic 0.063

How to read it: at 500 visitors the estimates range from 5.7% to 8.6%; at 5,000 they agree within a third of a percentage point. A sensitivity analysis like this belongs in every Bayesian report: if reasonable priors disagree, the data can't settle the question yet.

Has the sampler converged?

Picture it

Send four hikers from four different corners of a park to map it. If their maps agree, trust them. If each hiker only mapped the area around their own starting point, the maps disagree, and none of them is the whole park.

An MCMC chain starts somewhere arbitrary and needs time to reach the posterior; with steps that are too small it may never get there. So run several chains from very different starts and compare them with $\hat{R}$: the spread between chains relative to the spread within them. Near 1 means they agree; above about 1.01 means keep sampling or fix the sampler.

import numpy as np
data = np.array([2.9, 3.1, 2.4, 3.3, 2.7, 8.5, 2.8])
def log_post(m):
    return -np.sum(np.log1p((data - m) ** 2)) - m ** 2 / 200       # Cauchy likelihood, wide normal prior
def chain(start, step, n=4000, seed=0):
    rng, m, out = np.random.default_rng(seed), start, []
    for _ in range(n):
        prop = m + rng.normal(0, step)
        if np.log(rng.random()) < log_post(prop) - log_post(m):
            m = prop
        out.append(m)
    return np.array(out[n // 2:])                                    # drop the first half as warm-up
def r_hat(chains):
    c = np.array(chains); n = c.shape[1]
    W, B = c.var(axis=1, ddof=1).mean(), n * c.mean(axis=1).var(ddof=1)
    return np.sqrt(((n - 1) / n * W + B / n) / W)
for step in [0.5, 0.005]:
    chains = [chain(s, step, seed=i) for i, s in enumerate([-10, 0, 10, 20])]
    print("step", step, " chain means", [round(float(c.mean()), 2) for c in chains], " R-hat", round(float(r_hat(chains)), 2))

Output:

step 0.5  chain means [2.91, 2.91, 2.95, 2.9]  R-hat 1.0
step 0.005  chain means [-9.8, -0.06, 9.84, 20.19]  R-hat 122.7

How to read it: with step size 0.5, four chains starting at −10, 0, 10 and 20 all settle near 2.9, and $\hat{R}=1.0$. With step size 0.005 each chain barely moves from its start, and $\hat{R}=122.7$. Each of those chains alone would look perfectly smooth, which is why one chain is never enough. Stan and PyMC report $\hat{R}$ and the effective sample size automatically; check both.

In one breath

Re-run the analysis with several reasonable priors: if they agree, the data dominates; and run several MCMC chains from different starts, trusting the results only when R-hat is close to 1.

Hidden questions — answer in your head first, then open.

How do you check that an MCMC run is trustworthy?

The trap: "Look at the trace and it looks fine."

Run several chains from dispersed starting points; check that $\hat{R}$ is close to 1 (below about 1.01) and that the effective sample size is large enough for the quantities you report; inspect trace plots and, for HMC, divergent transitions. Then do posterior predictive checks: simulate data from the fitted model and compare with the real data.
