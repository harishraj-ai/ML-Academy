Undoing class weights: the prior correction

Picture it

If you train a model as if half of all transactions were fraud, it learns that fraud is common, and its probabilities are wildly too high. The prior correction tells it the real rate again, using Bayes' theorem.

Balanced weights (or oversampling to 50/50) make the model act as if positives and negatives were equally common. If the real positive rate is $\pi$, multiply the model's odds by the real prior odds:

$$\text{odds}_{\text{real}} = \frac{p}{1-p}\cdot\frac{\pi}{1-\pi}, \qquad p_{\text{real}} = \frac{\text{odds}_{\text{real}}}{1 + \text{odds}_{\text{real}}}$$

Worked example — correcting one prediction (real rate 2%)
  1. Balanced model says $p=0.6$: odds $0.6/0.4=1.5$.
  2. Real prior odds: $0.02/0.98\approx0.0204$.
  3. Corrected odds $1.5\times0.0204\approx0.031$, so $p\approx0.030$.
  4. "60% risk" really means about 3%: higher than average (2%), but far from likely.
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import brier_score_loss

X, y = make_classification(n_samples=40000, n_features=10, n_informative=5, weights=[0.98], flip_y=0, random_state=1)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.5, random_state=0, stratify=y)
pi = y_tr.mean()                                                    # true positive rate in training data
p_bal = LogisticRegression(max_iter=1000, class_weight="balanced").fit(X_tr, y_tr).predict_proba(X_te)[:, 1]

# Undo the reweighting: the model behaves as if positives were as common as negatives
odds = p_bal / (1 - p_bal) * (pi / (1 - pi))
p_fixed = odds / (1 + odds)
p_plain = LogisticRegression(max_iter=1000).fit(X_tr, y_tr).predict_proba(X_te)[:, 1]
for name, p in [("balanced weights", p_bal), ("balanced, corrected", p_fixed), ("plain model", p_plain)]:
    print(f"{name:20}: average predicted risk {p.mean():.3f} (true rate {y_te.mean():.3f})   Brier score {brier_score_loss(y_te, p):.4f}")

Output:

balanced weights    : average predicted risk 0.372 (true rate 0.020)   Brier score 0.1702
balanced, corrected : average predicted risk 0.017 (true rate 0.020)   Brier score 0.0178
plain model         : average predicted risk 0.020 (true rate 0.020)   Brier score 0.0169

How to read it: the balanced model predicts an average risk of 0.372 when the truth is 0.020 (Brier 0.1702). After correction: average 0.017, Brier 0.0178, almost as good as a model trained without weights (0.0169). So if you weight or resample to help the model learn the rare class, apply this correction (or recalibrate with CalibratedClassifierCV) before using the outputs as probabilities: pricing, expected losses, or telling someone their risk.

Why random splits isolate anomalies

Picture it

Play "guess who" with random yes/no questions. In a crowded room it takes many questions to single someone out. A person standing alone in the corner is singled out in one or two. Anomalies are the people in the corner.

Isolation Forest grows each tree by picking a random feature and a random split value, until every point sits alone. A far-away point is very likely cut off by one of the first few splits; a point deep in a cluster needs many.


# Isolation Forest's intuition: average number of random splits needed to isolate a point
rng = np.random.default_rng(0)
pts = np.vstack([rng.normal(0, 1, (500, 2)), [[6, 6]]])            # 500 normal points and one far away
def splits_to_isolate(i, trials=200):
    total = 0
    for _ in range(trials):
        idx = np.arange(len(pts)); depth = 0
        while len(idx) > 1:
            f = rng.integers(2); lo, hi = pts[idx, f].min(), pts[idx, f].max()
            t = rng.uniform(lo, hi)
            idx = idx[pts[idx, f] < t] if pts[i, f] < t else idx[pts[idx, f] >= t]
            depth += 1
        total += depth
    return total / trials
print("average splits to isolate the far point:   ", round(splits_to_isolate(500), 1))
print("average splits to isolate a typical point: ", round(np.mean([splits_to_isolate(i, 40) for i in range(10)]), 1))

Output:

average splits to isolate the far point:    2.3
average splits to isolate a typical point:  14.6
Worked example — turning path length into a score
  1. Far point: 2.3 splits on average; typical point: 14.6.
  2. The expected path for $n=500$ points is roughly $2\ln 500\approx12.4$.
  3. Much shorter than expected → anomaly score near 1; about as expected → around 0.5.

Because it never computes distances, Isolation Forest scales linearly with the data and copes with many features. Its main settings are the number of trees and the subsample per tree (256 by default, enough because anomalies stand out even in small samples).

In one breath

After class weighting or oversampling, multiply the odds by the real prior odds (or recalibrate) before trusting probabilities; Isolation Forest flags points that random splits separate quickly, because lone points need far fewer cuts.

Hidden questions — answer in your head first, then open.

You trained on a 50/50 resampled dataset, but the real positive rate is 1%. How do you get calibrated probabilities?

The trap: Using the raw scores as risks.

Apply the prior correction: multiply the model's odds by $\pi/(1-\pi)$ divided by the training odds (1 for 50/50), then convert back to a probability. Equivalently, add $\log\frac{\pi}{1-\pi} - \log\frac{\pi_{train}}{1-\pi_{train}}$ to the logit. Or recalibrate on a held-out set with the real class balance (Platt scaling or isotonic regression). Verify with a reliability table and the Brier score.
