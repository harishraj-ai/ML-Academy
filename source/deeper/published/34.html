New words for this section
  • Eigenvector: a vector that a matrix leaves pointing the same way (only rescaled).
  • Power iteration: multiply a vector by the matrix again and again until it stops changing.
  • Degree: the number of links a node has.
  • Laplacian $L=D-A$: degrees on the diagonal minus the link table.
  • Fiedler vector: the Laplacian's second eigenvector; it splits the graph.

PageRank is an eigenvector

Picture it

Pour water into a network of pipes and let it flow for a long time. Eventually the amount in each tank stops changing: water flowing in equals water flowing out. That steady state is PageRank.

The random surfer's moves form a matrix $G = \frac{1-d}{n}\mathbf{1}\mathbf{1}^\top + d M$: with probability $d$ follow a link ($M$), otherwise jump anywhere. PageRank is the vector with $rG = r$, an eigenvector with eigenvalue 1: "one more step changes nothing". Every entry of $G$ is positive, so the Perron–Frobenius theorem guarantees this eigenvector is unique and positive, which is why power iteration always finds it.

Worked example — two pages, by hand ($d=0.85$)
  1. A links to B and B links to A. Start $r=(0.9,0.1)$.
  2. Step: each page gets $0.15/2=0.075$ plus $0.85\times$ the other's share.
  3. A: $0.075+0.85\times0.1=0.16$; B: $0.075+0.85\times0.9=0.84$.
  4. Repeating, the swing shrinks by 0.85 each step and settles at $(0.5,0.5)$.

Here on a random directed graph of 60 nodes:

import numpy as np
rng = np.random.default_rng(3)
n = 60
A = (rng.random((n, n)) < 0.08).astype(float); np.fill_diagonal(A, 0)      # a directed graph
out = A.sum(axis=1, keepdims=True)
M = np.where(out > 0, A / np.maximum(out, 1), 1 / n)
G = 0.15 / n + 0.85 * M                                                     # the "Google matrix"
vals, vecs = np.linalg.eig(G.T)
lead = np.real(vecs[:, np.argmax(np.real(vals))]); lead = lead / lead.sum()
r = np.full(n, 1 / n)
for it in range(1, 101):
    r_new = r @ G
    if np.abs(r_new - r).sum() < 1e-10: break
    r = r_new
print("largest eigenvalue:", round(float(np.max(np.real(vals))), 6), "  power iteration converged in", it, "steps")
print("max difference from the eigenvector:", f"{np.abs(r - lead).max():.1e}")
print("correlation with in-degree:", round(np.corrcoef(r, A.sum(axis=0))[0, 1], 3), "  with out-degree:", round(np.corrcoef(r, A.sum(axis=1))[0, 1], 3))

Output:

largest eigenvalue: 1.0   power iteration converged in 27 steps
max difference from the eigenvector: 3.6e-12
correlation with in-degree: 0.724   with out-degree: -0.208

How to read it: the largest eigenvalue is exactly 1; power iteration converges in 27 steps and matches the eigenvector to $10^{-11}$. Errors shrink by about $d$ per step. PageRank correlates with in-degree (0.724), not out-degree (−0.208): links to a page count, links from it don't.

The graph Laplacian

Picture it

Give every node a number so that linked nodes get similar numbers. The smoothest pattern that isn't "everyone the same" naturally changes sign across the graph's weakest bridge, splitting it into two communities.

The Laplacian is $L = D - A$ ($D$ = degrees on the diagonal). For any node values $f$:

$$f^\top L f = \sum_{\text{edges } ij}(f_i - f_j)^2$$

In words: add up the squared differences across every link. It's small when linked nodes get similar values.

Worked example — a path of three nodes A–B–C
  1. Values $f=(1,0,-1)$: $(1-0)^2+(0-(-1))^2=2$.
  2. Values $f=(1,1,1)$: 0, the constant pattern, always eigenvalue 0.
  3. The smoothest non-constant pattern changes sign once, splitting the path into two sides.

Its smallest eigenvalue is always 0 (the constant vector); the eigenvector of the second-smallest, the Fiedler vector, tends to split the graph along its weakest cut:

sizes = [30, 30]; grp = np.repeat([0, 1], sizes)
P = np.where(grp[:, None] == grp[None, :], 0.25, 0.03)
B = np.triu(rng.random((60, 60)) < P, 1).astype(float); B = B + B.T
L = np.diag(B.sum(axis=1)) - B                                              # graph Laplacian
w, v = np.linalg.eigh(L)
fiedler = v[:, 1]                                                           # second-smallest eigenvector
split = (fiedler > 0).astype(int)
acc = max((split == grp).mean(), (split != grp).mean())
print("smallest Laplacian eigenvalues:", np.round(w[:3], 3).tolist())
print("splitting by the sign of the second eigenvector recovers the groups for", f"{acc:.0%}", "of nodes")

Output:

smallest Laplacian eigenvalues: [-0.0, 2.091, 3.272]
splitting by the sign of the second eigenvector recovers the groups for 100% of nodes

How to read it: eigenvalues 0, then 2.091; splitting nodes by the sign of the Fiedler vector recovers the two planted communities exactly. Spectral clustering uses several eigenvectors plus k-means. The same Laplacian appears in label spreading (Lesson 32) and in graph neural networks, where a layer smooths node features over neighbours.

In one breath

PageRank is the steady state of the random surfer, the eigenvector with eigenvalue 1, found reliably by power iteration; and the Laplacian's second eigenvector gives the smoothest split of a graph, the basis of spectral clustering.

How does spectral clustering work on a graph?

The trap: Calling it "k-means on the adjacency matrix".

Build the Laplacian L = D − A (or its normalised form), compute the eigenvectors for its k smallest eigenvalues, use them as new coordinates for each node, and run k-means there. Small eigenvalues correspond to smooth vectors that vary little across edges, so nodes in the same dense community get similar coordinates. The number of near-zero eigenvalues hints at the number of well-separated communities.
