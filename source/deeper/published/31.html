14.Going deeper: SARSA versus Q-learning on a cliff

In plain wordsQ-learning vs SARSA on a cliff walk: one learns the shortest route along the edge (perfect if you never slip), the other a safer route that accounts for its own random steps, and which is better depends on whether you're judged while learning or after.

New words for this section
  • ε-greedy: choose the best known action, but a random one ε of the time (here 10%).
  • Off-policy (Q-learning): learns the value of the best possible behaviour, even while exploring.
  • On-policy (SARSA): learns the value of what it actually does, exploration included.
  • Return: total reward collected in an episode.

Two learners, one cliff

Picture it

Walking home along a cliff path in the dark, knowing you sometimes stumble. A daredevil plans the shortest route along the very edge, assuming no stumbles. A careful walker, who remembers that they do stumble, takes a longer path away from the edge.

On a 4×8 grid the agent starts bottom left and must reach bottom right. The squares between are a cliff: stepping on one costs −100 and sends it back to the start; every other step costs −1. SARSA differs from Q-learning in one place: it updates towards the value of the action it will actually take next ($a'$, including random exploratory moves), not the best possible one:

$$Q(s, a) \leftarrow Q(s, a) + \alpha\big[r + \gamma\,Q(s', a') - Q(s, a)\big]$$

Worked example — one update, two rules
  1. Next to the cliff. Best next action is worth −8; the random action actually taken is worth −100 (it fell).
  2. Q-learning uses the best: target $-1+(-8)=-9$.
  3. SARSA uses the one taken: target $-1+(-100)=-101$. It learns that standing here is risky.
import numpy as np
# Cliff walking: a 4×8 grid; the bottom row between start and goal is a cliff (−100, back to start).
R, C = 4, 8
start, goal = (3, 0), (3, 7)
moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]
def env(s, a):
    i, j = min(max(s[0] + moves[a][0], 0), R - 1), min(max(s[1] + moves[a][1], 0), C - 1)
    if i == 3 and 0 < j < 7: return start, -100
    return (i, j), -1
rng = np.random.default_rng(0)
def train(method, episodes=500, alpha=0.5, eps=0.1):
    Q = np.zeros((R, C, 4))
    pick = lambda s: rng.integers(4) if rng.random() < eps else int(Q[s].argmax())
    for _ in range(episodes):
        s = start; a = pick(s)
        for t in range(200):
            s2, r = env(s, a); a2 = pick(s2)
            nxt = 0 if s2 == goal else (Q[s2].max() if method == "Q" else Q[s2][a2])
            Q[s][a] += alpha * (r + nxt - Q[s][a]); s, a = s2, a2
            if s == goal: break
    return Q
def route(Q):
    s, path = start, [start]
    for _ in range(40):
        s, _ = env(s, int(Q[s].argmax())); path.append(s)
        if s == goal: break
    return path
for method in ["Q", "SARSA"]:
    p = route(train(method))
    edge = sum(1 for c in p if c[0] == 2)                  # steps right next to the cliff
    print(f"{method:5s}: greedy route length {len(p) - 1}, steps along the cliff edge {edge}")

Output:

Q    : greedy route length 9, steps along the cliff edge 8
SARSA: greedy route length 13, steps along the cliff edge 2

How to read it: Q-learning learns the shortest route, 9 steps, 8 of them right along the cliff edge: perfect if you never slip. SARSA learns a 13-step route that stays away from the edge, because its own exploration sometimes takes a random step, and next to a cliff that's a disaster.

Which is better depends on when you're judged

Picture it

If you're graded on every practice session, playing safe wins. If you're graded only on the final exam, the bolder plan wins.

Measure the reward actually collected during learning, while both still explore 10% of the time:

def run_returns(method, episodes=500, eps=0.1):
    Q, total = np.zeros((R, C, 4)), []
    for _ in range(episodes):
        s, G = start, 0
        a = rng.integers(4) if rng.random() < eps else int(Q[s].argmax())
        for t in range(200):
            s2, r = env(s, a); G += r
            a2 = rng.integers(4) if rng.random() < eps else int(Q[s2].argmax())
            nxt = 0 if s2 == goal else (Q[s2].max() if method == "Q" else Q[s2][a2])
            Q[s][a] += 0.5 * (r + nxt - Q[s][a]); s, a = s2, a2
            if s == goal: break
        total.append(G)
    return np.mean(total[-200:])
q_ret = np.mean([run_returns("Q") for _ in range(5)]); s_ret = np.mean([run_returns("SARSA") for _ in range(5)])
print("average return while still exploring: Q-learning", round(q_ret, 1), "  SARSA", round(s_ret, 1))

Output:

average return while still exploring: Q-learning -31.2   SARSA -21.0

How to read it: SARSA collects more while exploring (−21.0 vs −31.2), because Q-learning's edge route often ends in the cliff when a random step happens. If exploration stops after training, Q-learning's route is better; if the agent keeps exploring, or a real robot sometimes slips, SARSA's caution pays. Where mistakes during learning are costly, that argues for on-policy or risk-aware methods, and for learning in simulation first.

In one breath

Q-learning learns the best route assuming perfect play, which hugs the cliff; SARSA learns the value of what it really does, including its random steps, so it takes a safer route and earns more while still exploring.

Hidden questions — answer in your head first, then open.

Explain on-policy versus off-policy reinforcement learning with an example.

The trap: Saying they're the same algorithm.

On-policy methods (SARSA, PPO) learn the value of the policy they're actually following, including its exploration; off-policy methods (Q-learning, DQN) learn about a different target policy, usually the greedy one, from data generated by another behaviour policy. On the cliff-walking task, Q-learning finds the optimal edge route but falls off often while exploring, while SARSA learns a safer route. Off-policy methods can reuse old or logged data, which on-policy ones can't easily do.
