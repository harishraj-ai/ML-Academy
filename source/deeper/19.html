Going deeper: attention and residual connections, from scratch

Intermediate · skip on a first read

Two ideas power nearly every modern architecture, from image models to large language models: attention, which lets each part of the input decide which other parts matter, and residual connections, which make networks with hundreds of layers trainable. This section builds both in a few lines of NumPy, measures why attention divides by $\sqrt{d}$, and explains how pretrained models are adapted to new tasks.

You'll need: this lesson, the softmax from Lesson 8, and vanishing gradients from Lesson 18's "Going deeper".

Attention, step by step

Each token (a word piece, or an image patch) is a vector. Three learned matrices turn it into a query ("what am I looking for?"), a key ("what do I contain?") and a value ("what will I pass on?"). Each token's output is a weighted average of all the values, where the weights come from how well its query matches each key:

$$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Row $i$ of the weight matrix shows how much token $i$ attends to each token, and each row adds up to 1. Token 2 (the second row) puts 78% of its attention on token 1, while token 3 spreads its attention almost evenly. Every token's output is computed in parallel by matrix products, which is why transformers train so efficiently on GPUs compared with RNNs, which must process one step at a time. Multi-head attention runs several of these in parallel with different matrices, so different heads can track different relationships (grammar, meaning, position), and concatenates their outputs.

Why divide by $\sqrt{d_k}$, measured

If query and key entries have variance 1, their dot product over $d$ dimensions has variance $d$, so its spread grows like $\sqrt{d}$. Large scores push the softmax towards a one-hot choice, where its gradients are almost zero, and learning stalls. Dividing by $\sqrt{d}$ brings the spread back to about 1. Unscaled, the average largest weight climbs from 0.62 at $d = 8$ to 0.95 at $d = 512$: almost every query locks onto a single key. Scaled, it stays about 0.31 at every size, so attention stays soft and trainable. (This lesson's "Advanced" box derives the variance argument.)

Residual connections

A residual block computes $\mathbf{h} + f(\mathbf{h})$ instead of $f(\mathbf{h})$: the layer learns a correction to its input rather than a whole new representation. In backpropagation the derivative of $\mathbf{h} + f(\mathbf{h})$ is $I + J_f$, so there is always an identity path for the gradient, however small $J_f$ becomes (Lesson 3's "Going deeper" described the chain rule as multiplying Jacobians). Without shortcuts, the gradient reaching the first layer is $2\times 10^{-14}$: effectively zero, so the early layers never learn. With shortcuts it's about 400. ResNets (2015) used this to train image networks with over 100 layers, and every transformer block wraps both its attention and its feed-forward part in a residual connection, usually with layer normalisation (Lesson 18's "Going deeper").

Positions, and putting a transformer block together

Attention on its own treats the input as an unordered set: shuffle the tokens and each output just moves with its token. Word order is reintroduced with positional encodings added to the token vectors: the original transformer used sine and cosine waves of different frequencies, $PE_{(p, 2i)} = \sin(p/10000^{2i/d})$, and many modern LLMs use rotary encodings (RoPE), which rotate queries and keys by an angle that depends on position. One transformer block is then:

  1. Multi-head self-attention, plus a residual connection, then layer norm.
  2. A small feed-forward network applied to each token separately (usually two layers with a GELU activation), plus a residual connection, then layer norm.

A language model stacks dozens of these blocks, uses a causal mask so each token can only attend to earlier tokens, and is trained to predict the next token.

Transfer learning and fine-tuning

Training a large model from scratch needs huge data and compute. Instead, start from a model pretrained on a broad task (images from ImageNet, or text from the web) and adapt it:

ApproachWhat's trainedWhen to use it
Feature extractionOnly a new output layer; the pretrained network is frozenVery little data; a task close to the pretraining task
Fine-tuningAll or the top layers, with a small learning rateA moderate amount of data; the best accuracy
Parameter-efficient fine-tuning (LoRA, adapters)Small added matrices; the original weights are frozenLarge language models: much less memory and storage per task
Prompting / in-context learningNothingLLMs, when instructions and a few examples are enough

LoRA uses an idea from Lesson 2's "Going deeper": it learns the change to a big weight matrix as a product of two thin matrices, $\Delta W = BA$ with rank $r$ of perhaps 8 or 16, so a $4096 \times 4096$ layer needs about $2 \times 4096 \times 8 = 65{,}536$ new numbers instead of 16.8 million.
