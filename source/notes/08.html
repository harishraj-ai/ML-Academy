Logistic regression

1From numbers to yes/no

Spam? Will the customer cancel? Malignant? Will the student pass? These are binary classification: $y=1$ (positive class) or $y=0$. Logistic regression is the standard first model. Despite its name it's a classifier, and it outputs a probability ("83% likely to pass"), which is far more useful for decisions.

Running example
Hours studied 0.5 … 5 vs passed (0/1): 0, 0, 0, 1, 0, 1, 0, 1, 1, 1. More study helps, but it's no guarantee: exactly the uncertainty probabilities describe.

2Why not linear regression?

  • A line goes on forever → "probabilities" like 1.4 or −0.3.
  • One student who studied 40 hours flattens the whole line and shifts everyone's decision point.
  • Squared error isn't the right way to score yes/no predictions.

3The sigmoid

$\sigma(z)=\dfrac{1}{1+e^{-z}}$

Values: σ(−4) = 0.018, σ(−1) = 0.269, σ(0) = 0.5, σ(1) = 0.731, σ(4) = 0.982. Symmetric: $\sigma(-z)=1-\sigma(z)$. Its derivative is neat: $\sigma'(z)=\sigma(z)(1-\sigma(z))$. It turns an unlimited "score" into a "confidence".

4The model

$z=\mathbf{w}\cdot\mathbf{x}+b,\qquad p=\sigma(z)=P(y=1\mid\mathbf{x})$

Example from the lesson
Trained model $z=1.354x-3.723$.
2 hours: $z=-1.015$ → $p\approx$ 0.27. 4 hours: $z=1.693$ → $p\approx$ 0.84.

5The decision boundary

Predict 1 when $p\ge0.5$, which happens exactly when $\mathbf{w}\cdot\mathbf{x}+b\ge0$. The boundary $\mathbf{w}\cdot\mathbf{x}+b=0$ is a straight line (plane): logistic regression is a linear classifier.

Example
$1.354x-3.723=0$ → x ≈ 2.75 hours: below it "fail", above "pass".
The threshold is a choice
Cancer screening: flag at $p\ge0.1$ (more false alarms, fewer misses). Spam filter: require $p\ge0.9$ so real emails get through.

6Reading the weights: odds

Odds $=\frac{p}{1-p}$ (0.8 → 4 to 1). The model is linear in the log-odds (logit): $\ln\frac{p}{1-p}=\mathbf{w}\cdot\mathbf{x}+b$. So +1 in $x_j$ multiplies the odds by $e^{w_j}$.

Example
$e^{1.354}\approx3.87$: each extra hour multiplies the odds of passing by about 3.9. A weight of $\ln2$ doubles them. The probability itself changes by different amounts at different places.

7The loss: log loss

$\ell=-[\,y\ln p+(1-y)\ln(1-p)\,]$

Only one term is active: $-\ln p$ if $y=1$, $-\ln(1-p)$ if $y=0$. True label 1:

  • $p=0.9$ → 0.105 (confident and right)
  • $p=0.5$ → 0.693 (unsure)
  • $p=0.1$ → 2.303 (confident and wrong)
  • $p=0.01$ → 4.605 (very confident and wrong)

As $p\to0$ the loss → ∞: confident mistakes are punished hard. It's also the maximum-likelihood loss for yes/no outcomes.

8The gradient: surprisingly simple

Chain rule: $\frac{\partial\ell}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial w_j}$, and the first two multiply out to just $p-y$:

$\dfrac{\partial L}{\partial\mathbf{w}}=\dfrac1n\sum(p_i-y_i)\,\mathbf{x}_i$

Same shape again
(prediction − truth) × input, exactly like linear regression. No formula for the answer, so we use gradient descent.

9The demo

Add points of two classes and train. The background shows the probability; the white line is the boundary. Put one class in a ring around the other and a straight boundary can't separate them.

10More than two classes

  • One-vs-rest: $K$ yes/no models ("a 3 or not?"), pick the most confident.
  • Softmax: a score per class, turned into probabilities that sum to 1: $P(y=k)=\frac{e^{z_k}}{\sum_je^{z_j}}$.
Example
Scores cat 2, dog 1, rabbit 0 → $e^z$ = 7.39, 2.72, 1 (total 11.11) → 66.5% / 24.5% / 9%.

★Going deeper: a probability model

Why the loss is convex

Gradient $X^\top(\mathbf{p}-\mathbf{y})$; Hessian $H=X^\top SX$ with $S=\text{diag}(p_i(1-p_i))$. Every $p_i(1-p_i)>0$, so $H$ is positive semi-definite everywhere: one valley, no bad local minima. Note $p(1-p)$ is largest (0.25) near the boundary and tiny for confident points, so confident points hardly shape the curvature.

How libraries solve it: Newton / IRLS

With a moderate number of features the Hessian is cheap, so use Newton's method; each step is a weighted least-squares problem, hence IRLS (iteratively reweighted least squares). An L2 penalty adds $\lambda\mathbf{w}$ to the gradient and $\lambda I$ to the Hessian.

Example from the lesson
Breast-cancer data, 5 features: step sizes $6\times10^{-4}$ → $1.5\times10^{-7}$ → $8\times10^{-15}$. Correct digits roughly double each step (quadratic convergence); 9 steps match scikit-learn to 4 decimals.
scikit-learn's C
$C=1/\lambda$: smaller C = stronger regularization. It's on by default. Without it, perfectly separable data sends the weights to infinity.

Calibration: can you trust the probabilities?

Well calibrated = of all cases scored 0.8, about 80% are positive. Accuracy and AUC ignore this (they only care about order). Check with a reliability table (bin predictions, compare with the actual rate) and the Brier score = mean of $(p_i-y_i)^2$.

Example from the lesson
Logistic regression: bins line up (0.02 → 0%, 0.98 → 99%), Brier 0.018. Gaussian naive Bayes: 107 cases at 0.00 but 10% positive, Brier 0.071 (4× worse), because it counts correlated evidence several times.

Fix a badly calibrated model with CalibratedClassifierCV: Platt scaling or isotonic regression, on held-out data.

When one class is rare

Example from the lesson
5% positives. Default model: recall only 7.5%, but honest probabilities (average 0.055 vs true 0.054). With class_weight="balanced" (each positive counts ~19×): recall 82.2%, precision 0.187, and the average prediction is 0.314, nowhere near 5%.
  • Need trustworthy probabilities (pricing, expected cost)? Keep the model unweighted and move the threshold.
  • Only need decisions? Either works.
  • Oversampling / SMOTE acts like reweighting, and must happen only inside training folds.

Softmax gradient

$\nabla_WL=\mathbf{x}(\mathbf{p}-\mathbf{y})^\top$ with $\mathbf{y}$ one-hot. "Prediction minus truth, times input" appears in linear regression, logistic regression, softmax and a network's output layer, because all are generalised linear models trained by maximum likelihood with their natural link.

✎ in one line: a linear score squashed into a probability, trained with log loss, turned into a decision by a threshold you choose.
