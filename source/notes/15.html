Support vector machines

1Which line is best?

If two classes can be split by a line, infinitely many lines do it. Logistic regression picks one by likelihood. An SVM picks the line that stays as far as possible from both classes: the widest safety corridor.

The widest road
Build a straight road between two villages. One that grazes a house is risky; the safest is the widest road through the middle of the gap. The houses at its edges are the support vectors.

2Labels ±1 and a hyperplane

Labels $y=+1$ / $-1$. Boundary $\mathbf{w}\cdot\mathbf{x}+b=0$; predict $\text{sign}(\mathbf{w}\cdot\mathbf{x}+b)$.

distance to the boundary $=\dfrac{|\mathbf{w}\cdot\mathbf{x}+b|}{\|\mathbf{w}\|}$

Handy trick: correctly classified exactly when $y_i(\mathbf{w}\cdot\mathbf{x}_i+b)>0$ (label and score have the same sign).

3The margin

Fix the scale so the closest points score exactly ±1: every point must satisfy $y_i(\mathbf{w}\cdot\mathbf{x}_i+b)\ge1$. The two "gutters" (score ±1) are each $1/\|\mathbf{w}\|$ from the boundary:

margin width $=\dfrac{2}{\|\mathbf{w}\|}$

Example
$\|\mathbf{w}\|=4$ → margin $2/4=$ 0.5.

4The optimisation problem

Wide margin = small $\|\mathbf{w}\|$. The hard-margin SVM:

$\min\tfrac12\|\mathbf{w}\|^2\quad\text{subject to}\quad y_i(\mathbf{w}\cdot\mathbf{x}_i+b)\ge1$

"The widest road, with every point off the road on its correct side." Convex, with one best solution. Only the points on the gutters (the support vectors) fix it: delete a far-away point and nothing changes.

5Soft margins and the hinge loss

Real data overlaps, so let points violate the margin at a price:

$\ell_{\text{hinge}}=\max\big(0,\;1-y_i(\mathbf{w}\cdot\mathbf{x}_i+b)\big)$

Example: a positive point
score 1.5 → 0 (safe, no penalty) · score 0.4 → 0.6 (right side, inside the road) · score −0.5 → 1.5 (wrong side).
Negative point ($y=-1$) with score 0.5 → $\max(0,1+0.5)=1.5$.

Unlike log loss, hinge loss is exactly 0 once a point is safe, so those points stop mattering.

$\min\;\tfrac12\|\mathbf{w}\|^2+C\sum\text{hinge}_i$

  • Small C: wide road, more violations allowed (more regularization).
  • Large C: narrow road, tries to classify every point (can overfit).

6The demo

Change C and watch the road widen and narrow; ringed points are support vectors. Add points: only points near the road change it.

7The kernel trick: curved boundaries

Example: lifting the data
1-D: class +1 at −3, 3; class −1 at −1, 0, 1 (in the middle, so no threshold works). Add a feature $x^2$: +1 → (±3, 9), −1 → (−1, 1), (0, 0), (1, 1). Now a horizontal line (e.g. $x^2=5$) separates them!

A kernel computes dot products in that bigger space without ever building it. The RBF kernel $K=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$ measures similarity; γ sets how far each point's influence reaches (bigger γ = wigglier boundary).

Recipe
Scale features → RBF kernel → tune C and γ together by CV. 100% train / 70% test? Lower γ and/or C.

8SVMs in practice

  • Scale your features (distances and dot products depend on scale).
  • Size limits: kernel training grows between $n^2$ and $n^3$; fine up to tens of thousands. Bigger: LinearSVC or SGDClassifier(loss="hinge").
  • No probabilities, just scores; SVC(probability=True) adds calibration at extra cost.
  • Regression: SVR ignores errors smaller than ε (a "tube").

★Going deeper: the dual, kernels, hinge loss

The dual problem and KKT

With Lagrange multipliers $\alpha_i$, the soft-margin SVM becomes:

$\max_{\alpha}\sum\alpha_i-\tfrac12\sum_{i,j}\alpha_i\alpha_jy_iy_j(\mathbf{x}_i\cdot\mathbf{x}_j),\quad0\le\alpha_i\le C,\;\sum\alpha_iy_i=0$

with $\mathbf{w}=\sum\alpha_iy_i\mathbf{x}_i$. From the KKT conditions:

  • Only support vectors matter: safe points get $\alpha_i=0$; points on the margin $0<\alpha_i<C$; inside or wrong $\alpha_i=C$.
  • Data appears only through dot products $\mathbf{x}_i\cdot\mathbf{x}_j$. Swap in a kernel $K(\mathbf{x}_i,\mathbf{x}_j)$: that's the whole kernel trick.

The kernel trick, checked

$(\mathbf{x}\cdot\mathbf{z}+1)^2$ in 2-D equals an ordinary dot product of 6 features $\phi=(1,\sqrt2x_1,\sqrt2x_2,x_1^2,x_2^2,\sqrt2x_1x_2)$. In the lesson both give 4.0, but the kernel needed one 2-D dot product. Degree $p$ in $d$ dimensions grows like $d^p$; RBF corresponds to infinitely many features. A function is a valid kernel when its matrices are positive semi-definite (Mercer's condition).

How C and γ interact

Example from the lesson
γ = 30, C = 100: train 1.000, test 0.845 (wraps around single points).
γ = 30, C = 0.1: collapses to 0.470 (almost one class).
Best around C = 1, γ = 1: 0.910.

Diagnostic: when nearly every point is a support vector (193 of 200), the model hasn't found a simple boundary.

Hinge loss vs logistic regression

$\min\;\tfrac{1}{2C}\|\mathbf{w}\|^2+\sum\max(0,1-y_if(\mathbf{x}_i))$

Logistic regression uses $\log(1+e^{-yf(\mathbf{x})})$, a smooth hinge that never reaches 0. On 400 points the two boundaries point the same way to three decimals and agree on every prediction. SVM: sparse support vectors, pure max-margin, no probabilities. Logistic regression: every point counts, calibrated probabilities.

Scaling up

Kernel SVMs need the $n\times n$ kernel matrix ($O(n^2)$ memory). Beyond ~100,000 points: a linear SVM, or approximate the kernel with random features (RBFSampler, Nystroem) + a linear model. SVR: only points outside the ε-tube become support vectors.

✎ in one line: the widest road between the classes; C trades width for mistakes; kernels bend the road.
