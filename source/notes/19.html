Deep learning architectures

1What makes learning "deep"?

Many layers, each building on the last. In an image network: edges → textures and shapes → eyes, wheels, letters. The network learns this hierarchy itself. A fully connected network ignores structure we know is there (nearby pixels belong together; word order matters), so deep learning's wins come from architectures built around that structure: CNNs for images, RNNs for sequences, Transformers for language.

2Making deep networks trainable

Backprop multiplies slopes layer by layer; sigmoid's slope is at most 0.25, so 10 layers can shrink a gradient by $0.25^{10}\approx10^{-6}$: the vanishing gradient problem.

  • ReLU: slope exactly 1 for positive inputs.
  • Careful initialisation (He, Glorot).
  • Normalisation layers (batch / layer norm).
  • Residual (skip) connections: let the gradient flow straight back.
  • Adam for optimisation; dropout against overfitting.

3CNNs: for images

A 224×224 colour image = 150,528 inputs; 1,000 fully connected neurons would need 150 million weights and learn "cat ear" separately for every position. Two ideas fix it:

  • Local connections: each neuron looks at a small patch (e.g. 3×3).
  • Weight sharing: the same small kernel slides over the whole image, so a detector learned in one place works everywhere.

output size $=\dfrac{W-F+2P}{S}+1$

Example
32×32 input, 5×5 kernel, padding 0, stride 1 → $(32-5)/1+1=$ 28.

Pooling shrinks the map (e.g. max of each 2×2). A typical CNN: conv + pool layers shrink the image while increasing the number of feature maps, then a dense layer scores each class.

4The convolution demo

On a real 8×8 digit: a vertical-edge kernel lights up the left and right edges of the strokes; a horizontal one finds tops and bottoms.

5RNNs and LSTMs: sequences

Order matters and lengths vary. An RNN reads one step at a time, carrying a hidden state (memory):

$\mathbf{h}_t=\tanh(W_h\mathbf{h}_{t-1}+W_x\mathbf{x}_t+\mathbf{b})$

The same weights at every step. Problem: training multiplies by $W_h$ again and again, so gradients vanish or explode; plain RNNs forget beyond about 10–20 steps.

LSTMs add a cell state and gates (forget, input, output) that decide what to keep, so information and gradients flow across many steps. GRUs are a simpler variant.

6Transformers and attention

The party
You hear your name across a noisy room and tune in to that conversation. Attention lets each word tune in to the words that matter for it.

RNNs read one word at a time (slow, long-range links are hard). The Transformer (2017, "Attention Is All You Need") lets every position look at every other position at once.

$\text{softmax}\!\left(\dfrac{QK^\top}{\sqrt{d_k}}\right)V$

Each token makes a query (what am I looking for?), a key (what do I contain?) and a value (what do I pass on?). Query · key = relevance; softmax → weights; output = a weighted mix of values. Runs in parallel on GPUs, which is why it powers language models.

7Transfer learning

Don't train from scratch: take a model pretrained on millions of images or billions of words and fine-tune it on your smaller dataset. Its early layers already know general features (edges, word meanings). That's how most practical deep learning is done.

8Tools

scikit-learn's MLPClassifier is fine for small fully connected networks but has no convolutions, recurrence, attention or GPU. For deep learning use PyTorch or TensorFlow/Keras: automatic gradients (autograd) and GPUs.

Remember model.eval() before evaluating (switches dropout off), and prefer ReLU over sigmoid in hidden layers.

★Going deeper: attention and residual connections, from scratch

Attention, step by step

At a noisy party you can't listen to everyone equally. You tune in to the people talking about what you care about. In attention, each word has a question (query); every word wears a label (key); a word listens most to those whose labels match its question, and takes in what they say (their values).

One token, three keys
Match scores (after scaling): 2, 1, 0.
$e^2, e^1, e^0 = 7.39, 2.72, 1.00$; total 11.11.
Weights: $0.67, 0.24, 0.09$ (they add to 1).
Output $=0.67\,v_1+0.24\,v_2+0.09\,v_3$: mostly token 1's information.

Why divide by $\sqrt{d_k}$, measured

Longer vectors give bigger dot products, just as adding more numbers gives a bigger total. Very big scores make softmax put nearly all weight on one item, and then its slope is almost zero, so learning stalls. Dividing by $\sqrt{d}$ calms the scores back down.

The size effect
Entries with variance 1, $d=64$ dimensions: dot products have variance 64, so spread $\sqrt{64}=8$.
Scores like 8 vs 0 give softmax weights of about $e^8/(e^8+1)\approx0.9997$: one-hot.
Divide by 8: spread back to about 1, a soft, trainable mix.

Residual connections

Instead of rewriting the whole essay at each draft, each editor only adds corrections in the margin. The original text always gets through, so even after 50 editors it's still readable. A residual block works the same way, and so does the learning signal flowing backwards.

Why the "+1" saves the gradient
Plain: each of 50 layers multiplies the gradient by about 0.5: $0.5^{50}\approx9\times10^{-16}$.
Residual: each layer multiplies by about $1+( ext{something small})$, so the product stays around 1 or above instead of collapsing to zero.

Positions, and putting a transformer block together

Attention alone sees a bag of words: "dog bites man" and "man bites dog" look identical. Adding a position signal to each word, like a seat number, puts the order back.

Transfer learning and fine-tuning

A doctor who already knows anatomy learns a new speciality far faster than someone starting from zero. A pretrained model already knows edges and shapes, or grammar and facts; you only teach it the last part.

How much LoRA saves
A $4096\times4096$ layer has $4096^2\approx16.8$ million weights.
LoRA with $r=8$: $B$ is $4096\times8$, $A$ is $8\times4096$: $2\times4096\times8=65{,}536$ new numbers.
About 256× fewer to train and store.
In one breath
Attention lets each token mix in information from the tokens whose keys match its query, with scores divided by $\sqrt{d}$ so softmax stays soft; residual connections give gradients a direct path through deep stacks; positional encodings restore word order; and fine-tuning a pretrained model (cheaply, with LoRA) beats training from scratch.
✎ in one line: CNNs for grids, RNNs/LSTMs for steps, transformers for "everything attends to everything", and fine-tune a pretrained model.
