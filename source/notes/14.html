Random forests & boosting

1The wisdom of crowds

In 1906, about 800 people at a fair guessed an ox's weight. Individual guesses were all over the place, but their median was within 1% of the truth. Ensembles do this with models: train many, combine their predictions. A single tree is unstable (Lesson 13); ensembles turn that into a strength. Random forests and gradient boosting win a large share of real-world tabular competitions.

2Why combining works

25 classifiers, each right 60% of the time, making mistakes independently. A majority vote is right when at least 13 are right:

$P=\sum_{k=13}^{25}\binom{25}{k}0.6^k0.4^{25-k}\approx0.846$

The catch
Twenty-five 60% models make an 85% team, but only if their mistakes differ. Copies of the same model don't help.

3Bagging: bootstrap aggregating

One training set, many different trees? Give each tree a bootstrap sample: draw $n$ rows from $n$ with replacement. Some rows appear twice, some not at all. Then average (or vote).

Example
Chance a row is never picked: $(1-\frac1n)^n\to e^{-1}\approx0.368$. So each sample holds about 63.2% of the distinct rows (n = 1000: $1-0.999^{1000}\approx0.632$).

4Random forests

Bagged trees are still similar (if one feature is strong, every tree splits on it first). A random forest (Breiman, 2001) also lets each split consider only a random subset of features, often $\sqrt d$ (max_features="sqrt"). The trees disagree more, so averaging helps more.

  • n_estimators: more is better up to a plateau; more trees never overfit, they only cost time.
  • max_features: smaller → more diverse but weaker trees.
  • Trees are usually grown deep; limit them on noisy data.

Popular because they work well with little tuning, handle mixed features, and need no scaling.

5Boosting: learning from mistakes

Bagging trains in parallel; boosting trains in sequence, each new model focusing on what the ensemble still gets wrong, usually with weak shallow trees (even depth-1 "stumps").

Like revising for an exam
Do a practice test, study the questions you got wrong, retest, repeat.

Bagging mainly cuts variance; boosting mainly cuts bias.

6AdaBoost

  1. Every example starts with an equal weight.
  2. Train a weak learner on the weighted data; weighted error ε.
  3. Its vote: $\alpha=\frac12\ln\frac{1-\varepsilon}{\varepsilon}$ (better learners shout louder).
  4. Misclassified weights × $e^{\alpha}$, correct ones × $e^{-\alpha}$, renormalise.
Example
10 examples at 0.1 each; a stump gets 3 wrong → ε = 0.3 → α = ½ ln(7/3) ≈ 0.42. The 3 mistakes get heavier, so the next stump focuses on them.

7Gradient boosting

  1. Start with a constant: $F_0=\bar y$.
  2. Residuals: $r_i=y_i-F_{m-1}(x_i)$, what's still wrong.
  3. Fit a small tree $h_m$ to the residuals.
  4. Add it, scaled by a learning rate: $F_m=F_{m-1}+\eta\,h_m$.
Example
True price 300, model so far 260 → residual +40. The next tree learns to add about +40 (× η) for houses like this one.

Why "gradient"? For squared loss, the residual is the negative gradient with respect to the prediction, so each tree is a gradient-descent step in prediction space. Swap the loss (log loss, absolute error) and you get a different "residual".

8The demo

Add stumps one at a time: the prediction becomes a better and better step-shaped fit, and the residual panel shows what the next tree will fix. Big learning rate vs small rate with many trees.

9Modern libraries

XGBoost, LightGBM, CatBoost: fast, polished gradient boosting. XGBoost adds tree regularization to the objective:

$\text{obj}=\sum_i\ell(y_i,\hat y_i)+\sum_k\Omega(f_k),\quad\Omega=\gamma T+\tfrac12\lambda\sum_jw_j^2$

($T$ = leaves, $w_j$ = leaf values). scikit-learn's HistGradientBoostingClassifier bins each feature into ≤ 255 bins, handles missing values, and early-stops automatically above 10,000 samples.

★Going deeper: tuning ensembles and how XGBoost works

Why averaging works: correlation is the limit

Asking 100 people to guess a jar of sweets works because their errors cancel out. But if they all copied the same person, you just have one guess written 100 times. Averaging only helps as much as the guessers think independently.

The floor in numbers ($\sigma^2=1$, 100 trees)
Independent trees ($\rho=0$): $0+1/100=0.01$.
$\rho=0.83$ (plain bagging here): $0.83+0.17/100\approx0.83$.
$\rho=0.70$: $\approx0.70$. Lower correlation, lower floor.
That's why a random forest lets each split look at only a random subset of features (max_features): it makes trees disagree more.

Tuning gradient boosting: learning rate and early stopping

Correcting an essay with many small careful edits usually beats a few big rewrites. A smaller learning rate keeps only part of each tree's correction, so you need more trees, but the result is usually better. Early stopping tells you when to stop adding them.

Reading the rows
Rate 1.0: stops after 35 trees, 0.924.
Rate 0.1: 83 trees, 0.947.
Rate 0.03: 203 trees, 0.936 (differences this small are within test-set noise).
Rule of thumb: halving the learning rate roughly doubles the trees needed.

What XGBoost, LightGBM and CatBoost add

Plain boosting knows which way is downhill (the slope). XGBoost also knows how curved the ground is, so it knows how far to step. And it charges a fee for every new leaf, so it only grows branches that clearly pay off.

One leaf value
Three rows in a leaf with slopes $g=-2, -1, 0$ (sum −3) and curvatures $h=1,1,1$ (sum 3). Penalty $\lambda=1$.
$w^*=-(-3)/(3+1)=0.75$.
Without the penalty it would be $3/3=1$; $\lambda$ shrinks leaf values, like ridge.

Stacking: combining different models

A team captain who listens to several experts and learns how much to trust each. To judge them fairly, the captain must test them on questions they didn't prepare for, otherwise everyone looks brilliant.

In one breath
Averaging helps only as much as trees disagree, so forests randomise features; use a modest learning rate with early stopping; XGBoost-style libraries add Newton steps and a price per leaf; and stack only strong models that make different mistakes, using out-of-fold predictions.
✎ in one line: forests average many different deep trees; boosting adds shallow trees that fix the leftover errors.
