Part 7 · Lesson 32

Semi-supervised & active learning

1When labels are scarce

Data is cheap, labels are expensive: millions of scans but few annotated by a radiologist; thousands of tickets but a few hundred tagged.

  • Semi-supervised: use the unlabelled data too, assuming its structure carries information about the labels.
  • Active learning: choose which examples to label, so each label teaches as much as possible.

The lesson uses scikit-learn's 1,797 handwritten digits, pretending only a few are labelled.

2The baseline: 50 labels

Example
30% held out for testing; of the 1,257 "pool" images only 50 random ones labelled → logistic regression 81.1%. With all 1,257: 97.2%. How much of that gap can we close?

3Why unlabelled data can help

  • Smoothness: nearby points tend to share a label.
  • Cluster: points form clusters, each mostly one label, so boundaries should pass through the empty gaps.
  • Manifold: data lies near a lower-dimensional surface along which labels change slowly.

When these hold (images, text, sensors), unlabelled points help draw the boundary. When they don't, it can make things worse, so always compare with the labelled-only baseline.

4Self-training with pseudo-labels

  1. Train on the labels.
  2. Predict the unlabelled data.
  3. Add the confident predictions as pseudo-labels, retrain, repeat.
Example from the lesson
Threshold 0.99: only 66 added → 81.9% (barely moves).
Threshold 0.9: 1,008 added, 5.8% wrong → 91.1%.
Threshold 0.6: 13% wrong → falls back to 87.2%.
Confirmation bias
Too low a threshold and the model learns its own mistakes. Tune it on a labelled validation set.

5Label spreading on a graph

Connect each point to its nearest neighbours; let the known labels flow along the edges until they settle. The smoothness assumption as an algorithm.

Example
From 50 labels, spreading labels 87.6% of the pool correctly; a classifier trained on them reaches 88.1%.

Needs a good distance and scaling; slow on very large datasets.

6Active learning

Let the model pick what a person labels. Uncertainty sampling: the examples it's least sure about, e.g. the smallest margin between its top two class probabilities (torn between two digits).

Example from the lesson
Start with 20 random labels, then 10 rounds of 15. With the same 170 labels: uncertainty 94.7% vs random 91.7%.
Careful
Pure uncertainty sampling can fill the set with weird outliers: mix in random picks, and start with a few labels of every class.

7The demo

Two classes, 300 points, 4 labelled. Ask for 5 more at a time, uncertain or random, and compare the boundary and accuracy for the same number of labels.

8Choosing an approach

  • Lots of unlabelled data, clear clusters → label spreading or self-training with a high threshold.
  • A labelling budget and a person available → active learning (uncertainty + some random).
  • Labels can be roughly produced by rules → weak supervision: combine noisy rules, train on the result.
  • Huge unlabelled image/text sets → self-supervised pretraining + fine-tuning.
  • A related task has many labels → transfer learning.
Always keep a properly labelled test set the method never touches. Never evaluate on pseudo-labels: they carry the model's own mistakes.

★Going deeper: when unlabelled data misleads, and committees

A wrong distance breaks label spreading

Asking neighbours for directions only helps if "neighbour" means someone who knows the area. If you choose neighbours by the colour of their car instead of where they live, their advice is useless. Label spreading is only as good as its notion of "near".

Reading the three numbers
Logistic regression on 20 labels: 91.9%. It learns to ignore feature 2.
Label spreading, raw features: 55.7%, near guessing. Neighbours are chosen by the noise.
After scaling: 86.4%. Better, but feature 2 still adds noise to every distance.

Query-by-committee

Ask a panel of judges about every case, and call in the expensive expert only for the cases where the judges argue the most. Those are the cases the expert's answer will teach the most.

Measuring disagreement
5 models vote on an image: "3, 3, 3, 3, 3" → full agreement; skip it.
Another image: "3, 8, 8, 3, 5" → strong disagreement; send it for labelling.
In one breath
Unlabelled data helps only when distances reflect how labels change, so scale and choose features and compare with a labelled-only baseline; query-by-committee sends for labelling the cases the models disagree on most, which helps most on hard, imbalanced problems.
✎ in one line: borrow structure from unlabelled data when the geometry is right, ask for the most useful labels, and test on real labels.
