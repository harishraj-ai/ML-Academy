Linear regression

1The idea

The "hello world" of ML, and still one of the most used models in industry. It predicts a number assuming the label changes in a straight-line way with each feature. Worth learning well: logistic regression, regularized models, SVMs and every neuron in a neural network reuse the same pattern, weights × features + bias.

2The model

$\hat{y}=wx+b\qquad\text{or}\qquad\hat{y}=\mathbf{w}\cdot\mathbf{x}+b$

$w$ (weight / slope) = change in $\hat{y}$ when $x$ goes up by 1. $b$ (bias / intercept) = the prediction at $x=0$. Two features → a flat plane; more → a "hyperplane".

3What does "best" mean? Least squares

Each residual $r_i=y_i-\hat{y}_i$ is a vertical gap. Ordinary least squares (OLS) minimises the mean of their squares:

$L(w,b)=\frac1n\sum\big(y_i-(wx_i+b)\big)^2$

  • Squaring makes every error positive, so ups and downs don't cancel.
  • Big errors cost much more (an error of 4 costs 16, an error of 1 costs 1).
  • The loss is a smooth bowl with one bottom, so calculus finds it.
Picture it
Each squared residual is the area of a little square. Least squares finds the line with the smallest total area.

4Solving with calculus

At the bottom of the bowl both partial derivatives are zero.

  • From $\partial L/\partial b=0$: $b=\bar{y}-w\bar{x}$, so the best line always passes through the average point $(\bar{x},\bar{y})$.
  • From $\partial L/\partial w=0$: the slope formula below.

$w=\dfrac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}$

5Worked example by hand

Example from the lesson
$x=1,2,3,4,5$; $y=2,4,5,4,5$ → $\bar{x}=3$, $\bar{y}=4$.
Top sum = 6, bottom sum = 10 → $w=$ 0.6, $b=4-0.6\times3=$ 2.2.
Line $\hat{y}=0.6x+2.2$; residuals −0.8, 0.6, 1.0, −0.6, −0.2 → squares sum to 2.4 → MSE = 0.48. Predict $x=6$: 5.8.

Read it as revision hours vs test score: each extra hour goes with about 0.6 more marks.

7How good is the fit? R²

MSE depends on units. $R^2$ compares the model with the laziest baseline, "always predict the mean":

$R^2=1-\dfrac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}}=1-\dfrac{\sum(y_i-\hat{y}_i)^2}{\sum(y_i-\bar{y})^2}$

  • 1 = perfect · 0 = no better than the mean · below 0 = worse than the mean (possible on test data).
Example
SSres = 2.4, SStot = 6 → $R^2=1-2.4/6=$ 0.6: the line explains 60% of the variation in scores.

8Many features: the normal equation

Add a column of 1s to $X$ so the bias is just another weight; then $\hat{\mathbf{y}}=X\mathbf{w}$. Setting the gradient $\frac2nX^\top(X\mathbf{w}-\mathbf{y})$ to zero gives:

$\mathbf{w}=(X^\top X)^{-1}X^\top\mathbf{y}$

The best weights can be calculated directly. For huge problems, gradient descent (Lesson 7) is faster.

9Reading the weights

price = 2.5·size + 12·bedrooms − 4·distance + 40 (in thousands) → holding the rest fixed, +1 m² ≈ +2.5k, +1 bedroom ≈ +12k, +1 km ≈ −4k.

Two cautions
• Units matter: standardise features first if you want to compare weights.
• Correlation ≠ causation: splitting a room into two won't necessarily add 12k.

10Limitations and fixes

  • Curved relationship → add features like $x^2$, $x^3$ (still linear in the weights).
  • Outliers pull the line a long way.
  • Correlated features make single weights unstable → regularization (Lesson 10).
  • Residuals should look like random noise. A curved pattern means something is missing.

★Going deeper: the statistics behind it

The four assumptions: LINE

  • Linearity: the average of $y$ is a straight-line function of the features. Check residuals vs predictions for curves.
  • Independence: one error says nothing about the next. Broken by time series and repeated measurements → standard errors too small.
  • Normality: errors follow a bell curve. Only matters for exact p-values in small datasets.
  • Equal spread (homoscedasticity): errors are as big for large predictions as small ones. If they fan out, the weights are fine but the standard errors are wrong.

The features and $y$ themselves don't need to be normal. And if you only care about test-set predictions, none of this is strictly needed; it matters when you claim "this feature has a real effect".

Why squared error?

  • It's the maximum-likelihood answer when noise is normal (with Laplace noise you'd get absolute error / median regression).
  • Gauss–Markov: with zero-mean, uncorrelated, equal-spread errors, OLS has the smallest variance among unbiased linear estimators ("BLUE"). But a slightly biased method like ridge can predict better.

How sure is each weight?

Fit on a different sample and the weights wobble. The standard error measures how much: $\text{Var}(\hat{\mathbf{w}})=\sigma^2(X^\top X)^{-1}$, with $\hat\sigma^2=\text{SS}_{\text{res}}/(n-d-1)$.

  • $t=\hat w/\text{SE}$: how many SEs from zero.
  • p-value: chance of a $|t|$ this big if the true weight were 0.
  • 95% interval: $\hat w\pm t^*\text{SE}$ (about ±1.97 SE here).
Example: diabetes data (442 patients)
bmi: 7.81 SEs from zero, interval 389 to 651 → clearly real. age: p = 0.867, interval −127 to +107 → can't even tell the direction. s1: big weight (−792) yet p = 0.058, because its SE (416.7) is huge.
A p-value is not…
…the chance the feature is useless. A large p doesn't prove "no effect" (maybe too little data). A tiny p doesn't mean big, useful or causal.

Overlapping features: the VIF

s1 (total cholesterol) and s2 (LDL) correlate about 0.9, so the model can't decide how to split the credit. The variance inflation factor: predict feature $j$ from the others, then

$\text{VIF}_j=\dfrac{1}{1-R_j^2}$

VIF 1 = no inflation; 10 = the others explain 90%. SE grows by $\sqrt{\text{VIF}}$. Investigate above 5–10.

Example
s1's VIF = 59.2 (SE ×7.7). Drop s2 → s1's SE falls from 416.7 to 114.0, while $R^2$ barely moves (0.5177 → 0.5155).

Multicollinearity hurts interpretation, not prediction.

Adjusted R² and cross-validation

Training $R^2$ never goes down when you add a feature, even pure noise. Adjusted $R^2=1-(1-R^2)\frac{n-1}{n-d-1}$ penalises each feature.

Example
Adding random noise columns: training $R^2$ climbs 0.518 → 0.633; adjusted stays about 0.51; cross-validated $R^2$ actually falls 0.482 → 0.277. CV tells the truth.

Errors that fan out: the log transform

Money-like targets vary in proportion to their size, so residuals fan out (senior salaries 3.4× more spread than juniors). Model $\log y$ instead: "±25%" becomes a constant "±0.25".

Reading it: +1 in $x$ multiplies $y$ by $e^w$. $e^{0.0591}=1.061$ → each extra year ≈ 6.1% higher salary (for small $w$, read $100w$ as a %). Converting back with $e^{\hat y}$ gives roughly the median. Alternatives: robust standard errors (HC3) or weighted least squares.

Points that bend the line

  • Outlier: $y$ far from the line.
  • High leverage: $x$ far from the others (the hat-matrix diagonal $h_{ii}$; average $(d+1)/n$).
  • Influential = both. Cook's distance measures how much all predictions move if the point is deleted; flag above 1 (or 4/n).

Robust regression (e.g. Huber loss) limits how much any single point can pull.

Categories: the dummy-variable trap

One-hot encode a category with $k$ values and keep only $k-1$ columns when there's an intercept. All $k$ columns add up to the 1s column, so $X^\top X$ can't be inverted. The dropped category becomes the baseline the others are compared to.

✎ in one line: the line that minimises squared gaps, judged by R² against the mean, read carefully and checked for assumptions.
