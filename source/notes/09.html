Part 2 · Lesson 9

Evaluating models

1Why accuracy isn't enough

Accuracy = the share of correct predictions. But if a disease affects 1 in 100 people, a "model" that says healthy to everyone is 99% accurate and never finds a single sick person.

  • Flag everyone instead → finds every sick person, 1% accurate.
  • If half were sick, "always healthy" would score 50%.

How good an accuracy is depends on the base rate.

2The confusion matrix

P / N = what the model said.

T / F = was that right?

So a false positive (Type I error) is a wrong "yes", a false alarm. A false negative (Type II error) is a wrong "no", a miss.

The lesson's screening test
100 patients, 10 really sick. The model flags 18, of whom 8 are sick → TP 8, FN 2, FP 10, TN 80.

3Accuracy, precision, recall, specificity

The airport scanner
Beep at everything: never misses a threat, delays thousands. Beep at nothing: smooth queues, real danger. Precision and recall put numbers on that trade-off.
  • Accuracy $=\frac{TP+TN}{\text{all}}=\frac{88}{100}=$ 0.88
  • Precision $=\frac{TP}{TP+FP}=\frac{8}{18}\approx$ 0.44: when it says "yes", can I trust it?
  • Recall (sensitivity, TPR) $=\frac{TP}{TP+FN}=\frac{8}{10}=$ 0.80: does it find what it should?
  • Specificity (TNR) $=\frac{TN}{TN+FP}=\frac{80}{90}\approx$ 0.89: of the healthy, how many left alone?
Trick to remember
Precision looks at the Predictions. Recall looks at the Real positives.

4The F1 score

$F_1=2\cdot\dfrac{P\cdot R}{P+R}=\dfrac{2TP}{2TP+FP+FN}=\dfrac{16}{28}\approx0.57$

The harmonic mean is dragged down by the smaller value, so great recall can't hide terrible precision: precision 1.0 + recall 0.01 → ordinary average ≈ 0.5, but F1 ≈ 0.02.

$F_\beta$ weights recall β times as much: F2 favours recall (screening), F0.5 favours precision (spam filters).

5The threshold trade-off

No threshold is "correct" in general: choose it from what each kind of mistake costs.

6The threshold demo

The scores of real positives and negatives overlap (as in real life), so no threshold is perfect. Drag it and watch the confusion matrix, the metrics and the ROC point change together.

7ROC curve and AUC

Look at all thresholds at once: plot TPR (recall) against FPR $=\frac{FP}{FP+TN}$.

  • (0, 0) = flag nothing; (1, 1) = flag everything; top-left (0, 1) = perfect.
  • AUC = the chance the model ranks a random positive above a random negative: 0.5 = guessing, 1 = perfect.

8Precision–recall curves

When positives are rare (fraud, disease, defects), plot precision vs recall. Its summary, average precision (AP), has a baseline equal to the share of positives (0.01 for 1% fraud), much lower than ROC's 0.5, so differences show up more clearly.

9More than two classes

The confusion matrix becomes $K\times K$ (rows = true, columns = predicted); off-diagonal cells show which classes get mixed up (a "3" read as an "8"). Compute precision/recall per class, then average:

  • Macro: every class counts equally.
  • Weighted: by how many examples each class has.

10Metrics for regression

  • MAE $=\frac1n\sum|e_i|$: in the target's units, robust to outliers.
  • MSE $=\frac1n\sum e_i^2$ and RMSE $=\sqrt{\text{MSE}}$: punish big misses.
  • R²: share of variance explained (Lesson 6).
Example
True 3, 5, 2, 7; predicted 2.5, 5, 4, 8 → errors −0.5, 0, 2, 1. MAE = 0.875, MSE = 1.3125, RMSE ≈ 1.15, $R^2=1-5.25/14.75\approx$ 0.64. RMSE > MAE because the single error of 2 counts extra.

11Choosing the metric

  • Balanced classes, equal costs → accuracy.
  • Missing a positive is costly (disease, fraud) → recall, F2.
  • False alarms are costly (spam, legal flags) → precision, F0.5.
  • One number for imbalanced data → F1, average precision.
  • Threshold-free comparison → ROC-AUC (or AP if positives are rare).
  • Regression → MAE (all errors equal) or RMSE (big errors worse).
Always compare with a dumb baseline
95% accuracy is unimpressive if "always predict the most common class" gets 94%. And always measure on unseen data.

★Going deeper: comparing models honestly

Every score needs an error bar

A test set is a sample. With 171 test cases, one unusual case moves accuracy by about 0.6 points. Accuracy has a formula, $\sqrt{p(1-p)/n}$; for AUC, F1 or precision use the bootstrap. When comparing two models, bootstrap the difference on the same resampled cases (their scores move together).

Example from the lesson
Logistic regression AUC 0.996, depth-3 tree 0.904. 95% interval for the difference: 0.046 to 0.15. It excludes 0, so it's not a fluke. If it had crossed 0: "no clear winner".

Paired tests: McNemar

Only the cases where the two models disagree matter. If they were equally good, each disagreement would be a coin flip.

Example
Logistic regression right / tree wrong: 11 cases; the reverse: 1. A split this lopsided has probability 0.0063 if they were equal → logistic regression really is more accurate here.

With cross-validation the folds overlap, so plain t-tests are over-confident; use the corrected resampled t-test or the 5×2 CV test.

Choosing the threshold from costs

Flagging costs $c_{FP}(1-p)$ on average, not flagging costs $c_{FN}\,p$. Flag when

$p>\dfrac{c_{FP}}{c_{FP}+c_{FN}}$

(only valid with calibrated probabilities).

Example from the lesson
Missing a malignant tumour costs 20, a false alarm 1 → threshold $1/21\approx0.048$. At 0.5: 3 cancers missed, total cost 64. At 0.05: none missed, 18 false alarms, cost 18. (Choose it on validation data in real projects.)

ROC-AUC vs average precision for rare positives

TPR and FPR are rates within each class, so the ROC curve doesn't change when positives become rarer. Precision does: a small FPR then means many false alarms.

Example
Same model, positives from 50% down to 1%: ROC-AUC stays about 0.86; average precision falls from 0.855 to 0.136.

ROC-AUC asks "does it rank positives above negatives?"; AP asks "when it raises an alert, how often is it right?", which is what the people receiving the alerts experience.

A reporting checklist

  • The metric, chosen before seeing results.
  • A simple baseline.
  • A confidence interval.
  • A paired comparison (overlapping intervals don't prove "no difference").
  • The threshold and why.
  • Results by subgroup (averages can hide groups the model fails, Lesson 21).
✎ in one line: accuracy hides rare classes; ask "how many caught?" and "how many false alarms?", and put an error bar on every score.
