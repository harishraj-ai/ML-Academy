Python, NumPy & pandas

1Why Python?

Every lesson has Python code. This warm-up gives you just enough to read and run it: about an hour, no experience needed. Python reads almost like English, and the best ML libraries (scikit-learn, PyTorch, TensorFlow) use it. You don't need to memorise anything: come back whenever later code looks unfamiliar.

Learn by running
Type the code yourself in the Lesson 0 notebook, run it, change something, run it again.

2Running code

Install Python and JupyterLab once (see Setup). A notebook is a list of cells: type code, press Shift + Enter, the output appears underneath.

  • print("Hello") shows something. Text goes inside quotes.
  • Anything after # is a comment: a note for humans that Python ignores.

3Variables and arithmetic

A variable is a name for a value. = means "store this under this name", not the maths equals. You can overwrite it any time.

  • ** = to the power of: 2 ** 3 → 8.
  • / always gives a decimal: 7 / 2 → 3.5.
  • // divides and drops the remainder: 7 // 2 → 3.

4Text (strings)

Text values are strings. An f-string drops variables into text: f"Price: {price:.2f}", where :.2f rounds to 2 decimal places.

5Lists and indexing

A list holds values in order: prices = [10, 20, 30, 40]. Positions count from 0, and negative positions count from the end (prices[-1] = last).

The off-by-one trap
A slice [start:stop] stops before stop: [1:3] has 2 items. The last of 5 items is [4]; [5] is an error.

6Dictionaries

Values stored under names (keys) instead of positions, like one row of a table: home = {"city": "Chennai", "size": 90} → home["city"].

7if and for

  • if runs code only when a condition is true.
  • for repeats a block once per item. range(n) gives 0 … n−1.
  • The indented lines (4 spaces) belong to the if/for. In Python, indentation is part of the syntax.
  • A list comprehension builds a list in one line: [p * 2 for p in prices].

9Libraries

import numpy as np, import pandas as pd, import matplotlib.pyplot as plt: these three lines start almost every notebook in the course. as just gives a short nickname.

10NumPy: numbers in bulk

Arithmetic on an array applies to every element at once, no loop needed. This is vectorisation: shorter and much faster.

plain list: [1, 2] * 2 → [1, 2, 1, 2] (repeats!)
NumPy: np.array([1, 2]) * 2 → [2, 4] (doubles ✓)
  • 2-D arrays = rows × columns (examples × features). .shape gives the size, e.g. (100, 5).
  • X.mean(axis=0) = down the rows → one result per column.
  • Comparisons give True/False arrays you can filter with: x[x > 3].
  • X @ w multiplies a matrix by a vector: each row dotted with the weights (Lesson 2).

11pandas: tables

A DataFrame is a table with named columns. The course's running example is 12 houses in Chennai:

  • df = pd.read_csv("houses.csv") loads it.
  • df["price"] → one column (acts like a NumPy array).
  • df[df["price"] > 80] → only the matching rows. (df["price"] > 80 alone is just True/False.)
  • df.groupby("area")["price"].mean() → a summary per group.
  • df["per_m2"] = df["price"] / df["size"] → a new column from old ones.

12A first plot

plt.scatter(df["size"], df["price"]): price against size is the first thing to look at before fitting a model. Bigger houses tend to cost more, with plenty of scatter (distance and age matter too).

13Reading errors

Errors are normal. Python prints a traceback; the last line says what went wrong.

  • NameError: a typo, or a variable used before its cell was run. Run cells from the top.
  • TypeError: mixing types, e.g. "Price: " + 72. Use str(72) or an f-string.
  • IndexError: counting from 1 instead of 0.
  • ValueError (shape mismatch): arrays of different sizes. Print .shape: the most useful debugging habit in ML.
When stuck
Read the last line → check spelling, brackets, quotes, indentation → restart and run all → search the exact error message.
✎ in one line: count from 0, let NumPy do the loops, check .shape, read errors from the bottom.
