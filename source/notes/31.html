Reinforcement learning basics

1Learning by acting

Supervised learning is told the right answer for every example. Often nobody knows the right move, only whether things went well in the end: a robot reaching a charger, a game won, a thermostat saving energy while keeping people comfortable. Reinforcement learning learns from such delayed rewards by acting, seeing what happens and adjusting. (Lesson 28's bandits were the simplest case: one decision, no state.)

2Markov decision processes

  • States $s$, actions $a$.
  • Transitions $P(s'\mid s,a)$: where an action leads, maybe at random.
  • Rewards $R$ after each step.
  • Discount $\gamma\in[0,1]$: how much future rewards count.

"Markov" = the next state depends only on the current state and action, not the history. A policy $\pi(s)$ says what to do in each state; we want the one with the highest expected discounted return $r_1+\gamma r_2+\gamma^2r_3+\dots$

γ = how far ahead it looks
Near 0: only the next reward (short-sighted). Near 1: plans for the long run.

3Values and the Bellman equation

$V(s)=\max_a\sum_{s'}P(s'\mid s,a)\big[R(s')+\gamma V(s')\big]$

Try each action, average over where it might lead, take the best. Value iteration: start all values at 0, apply this to every state, repeat until nothing changes.

One Bellman update (slippery grid, γ = 0.9)
The square left of the goal: moving → reaches the goal with probability 0.9 (+1, episode over); 0.05 each it slides up (stays put) or down. Averaging those outcomes gives that square's new value.

4From values to a policy

Pick the action that achieves the max. On the slippery grid the policy goes up the left side and along the top, away from the pit, rather than the shorter route past it: with a slippery floor the safe path has a higher expected return. But this needed the full transition probabilities, which real problems rarely give you.

5The value-iteration demo

Values spread outwards from the goal sweep by sweep. Lower γ → short-sighted; raise the slip chance → the policy steers further from the pit.

6Q-learning: no model needed

Learn $Q(s,a)$, the value of each action in each state, from single steps:

$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$

The bracket is the temporal-difference (TD) error: how surprised the agent was; move a fraction α towards the target. ε-greedy: usually the best-looking action, with probability ε a random one, or it never discovers better actions.

After 3,000 episodes of trial and error, Q-learning finds a sensible policy without ever being told the transition probabilities.

7Rewards shape behaviour

Example from the lesson
Small step cost → the long, safe route. A huge step cost (−2 per step) → from squares next to the pit the agent jumps in: ending at −1 beats wandering towards the goal.
Correct for the reward given, and a small case of reward hacking: agents maximise exactly the reward, loopholes included. Design rewards carefully, test them, add constraints.

8RL in practice

  • Model-based vs model-free: value iteration uses known transitions; Q-learning learns from experience.
  • On- vs off-policy: SARSA learns the policy it follows; Q-learning learns the optimal one while exploring.
  • Policy gradient (REINFORCE, PPO): adjust a policy directly towards higher return.
  • Function approximation: replace the Q table with a model (deep Q-networks) when there are too many states.
  • Offline RL: learn from logged data only; hard, because of distribution shift.
Before reaching for RL
It's data-hungry and hard to debug. Would a supervised model or a bandit do the job?

★Going deeper: SARSA versus Q-learning on a cliff

Two learners, one cliff

Walking home along a cliff path in the dark, knowing you sometimes stumble. A daredevil plans the shortest route along the very edge, assuming no stumbles. A careful walker, who remembers that they do stumble, takes a longer path away from the edge.

One update, two rules
Next to the cliff. Best next action is worth −8; the random action actually taken is worth −100 (it fell).
Q-learning uses the best: target $-1+(-8)=-9$.
SARSA uses the one taken: target $-1+(-100)=-101$. It learns that standing here is risky.

Which is better depends on when you're judged

If you're graded on every practice session, playing safe wins. If you're graded only on the final exam, the bolder plan wins.

In one breath
Q-learning learns the best route assuming perfect play, which hugs the cliff; SARSA learns the value of what it really does, including its random steps, so it takes a safer route and earns more while still exploring.
✎ in one line: act, collect rewards, update values with the TD error, keep exploring, and design the reward with care.
