Vectors & matrices

1Why bother?

A house = a list of numbers (size, bedrooms, distance). A dataset = a table of such lists. In maths a list is a vector and a table is a matrix. Almost all ML is written this way because one short line can describe operations on thousands of examples, and computers run it very fast.

2Vectors

An ordered list of numbers, e.g. $\mathbf{x}=(50,1,2)$: size 50, 1 bedroom, 2 km. It has 3 components $x_1,x_2,x_3$, so its dimension is 3: $\mathbf{x}\in\mathbb{R}^3$.

  • Picture it as a point: (3, 2) is 3 right, 2 up.
  • Or as an arrow from (0, 0): it has a direction and a length.

In ML each example is a point in "feature space", and similar examples are points close together.

3Adding and scaling

  • Add component by component: $(1,2)+(3,-1)=(4,1)$. Picture: walk along one arrow, then the other.
  • Scale every component: $3\cdot(1,2)=(3,6)$, the same direction but 3× longer. Times −1 flips it.
Where you'll see it
Gradient descent, $\mathbf{w}_{\text{new}}=\mathbf{w}-\eta\nabla L$, is just "scale one vector and subtract it from another".

4Length and distance

$\|\mathbf{v}\|=\sqrt{v_1^2+v_2^2+\dots+v_d^2}$

That's Pythagoras: $\|(3,4)\|=\sqrt{9+16}=5$. This is the Euclidean (L2) norm. The distance between two points is the length of their difference, $\|\mathbf{a}-\mathbf{b}\|$.

Example
House A = (5, 2), house B = (8, 6). Difference (3, 4) → distance 5. A "homes like this one" feature uses exactly this, and kNN (Lesson 11) too.

5The dot product (the star of ML)

Multiply matching entries, then add:

$\mathbf{a}\cdot\mathbf{b}=\sum_i a_ib_i$

Shopping bill
2 notebooks at ₹40, 3 pens at ₹10, 1 bag at ₹500 → $2\cdot40+3\cdot10+1\cdot500=610$. That's a dot product, and it's exactly how a linear model turns features and weights into a prediction.
Example
$(2,3,1)\cdot(4,-1,5)=8-3+5=$ 10. The second feature has a negative weight, so it pulls the score down; raise it from 3 to 6 and the score falls to 7.

It also measures how much two vectors point the same way: large = aligned, 0 = at right angles, negative = opposite. Dividing by both lengths gives the cosine similarity ($\cos\theta$, from −1 to 1).

6The demo

Drag the two arrows: the dot product is exactly 0 when they're at 90°.

7Matrices

A grid of numbers with shape rows × columns. The house dataset (4 houses × 3 features) is a 4 × 3 matrix $X$: each row is an example, each column a feature (the convention in scikit-learn too). $X_{32}=3$ means row 3, column 2 (house 3 has 3 bedrooms).

8Matrix × vector: all predictions at once

$X\mathbf{w}$ = each row dotted with $\mathbf{w}$.

Example from the lesson
Rows (size, bedrooms, age), $\mathbf{w}=(3,20,-5)$:
row 1: $3\cdot50+20\cdot1-5\cdot2=160$, then 255, 360, 515.
One expression $\hat{\mathbf{y}}=X\mathbf{w}$ gives every house's prediction. Add a bedroom to house 1 → its prediction rises by exactly 20 (160 → 180).

9Matrix × matrix

Every row of $A$ dotted with every column of $B$. $A$ ($m\times n$) times $B$ ($n\times p$) gives $m\times p$.

Example
$\begin{bmatrix}1&2\\3&4\end{bmatrix}\begin{bmatrix}5&6\\7&8\end{bmatrix}=\begin{bmatrix}19&22\\43&50\end{bmatrix}$ (e.g. $19=1\cdot5+2\cdot7$).
Swap the order: $BA=\begin{bmatrix}23&34\\31&46\end{bmatrix}$. Order matters: $AB\ne BA$.
Shape check
(m × n)(n × p) → (m × p). The inner sizes must match, e.g. (3×4)(4×2) → 3×2.

10Transpose and identity

  • Transpose $A^\top$: rows become columns (2×3 → 3×2). It mostly appears to make shapes line up: $\mathbf{a}^\top\mathbf{b}$, $X^\top X$ in Lesson 6.
  • Identity $I$: 1s on the diagonal, 0s elsewhere. Acts like the number 1: $I\mathbf{x}=\mathbf{x}$.

11In NumPy

Arrays for vectors and matrices; @ is matrix multiplication (or a dot product for two vectors); * is element-by-element. A.T is the transpose, np.eye(3) the identity.

★Going deeper: the linear algebra behind ML algorithms

Other ways to measure size: norms

Measuring a walk across a city. "As the crow flies" is the L2 norm. "Along the streets" (blocks east + blocks north) is the L1 norm. "The longest single stretch" is L∞. Same trip, three different sizes.

Three sizes of $(3,-4,1)$
L1: add the sizes, $3+4+1=8$.
L2: square, add, square-root: $\sqrt{9+16+1}=\sqrt{26}\approx5.1$.
L∞: the biggest one, $4$.
L1 ≥ L2 ≥ L∞ always holds.

Independence, rank and the determinant

Three ingredients on a recipe: flour, sugar, and "flour + sugar mix". The third adds nothing new: you could make it from the first two. Rank counts only the ingredients that are really new.

Spot the duplicate
Features: size, rooms, and size + rooms.
Column 3 = column 1 + column 2, so only 2 columns are new: rank = 2.
Then $X^\top X$ has determinant 0 and can't be inverted, so least squares has no single answer.
For $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$: $\det A = 2\cdot3-1\cdot1=5$, so it stretches any shape to 5× its area.

Eigenvalues and eigenvectors

Stretch a sheet of rubber. Most arrows drawn on it turn as well as stretch. A few special arrows only get longer or shorter, without turning. Those are eigenvectors; how much they stretch is the eigenvalue.

Eigenvalues of $A$, step by step
Write $\det(A-\lambda I)=0$: $(2-\lambda)(3-\lambda)-1=0$.
Multiply out: $\lambda^2-5\lambda+5=0$.
Solve: $\lambda=(5\pm\sqrt5)/2$, so $\lambda\approx3.618$ and $1.382$.
Check: they add to 5 (= 2 + 3, the diagonal) and multiply to 5 (= the determinant).
That last check is a quick way to catch mistakes.

Positive definite matrices

A bowl that curves upwards in every direction you walk. "Positive definite" means the matrix describes such a bowl; "semi-definite" allows some perfectly flat directions.

The singular value decomposition (SVD)

A big table of ratings is like a song mixed from a few instruments. The SVD un-mixes it: it finds the few hidden "instruments" (tastes like action, comedy, drama) and how loud each one is (the singular values).

Reading the singular values
Values drop sharply after the third: …, 38.5, then 3.9.
So 3 hidden tastes explain the table; the rest is noise.
Storage: 273 numbers for the rank-3 version instead of 2,000.
Error: 0.157 at rank 3, 0.142 at rank 5. Extra values hardly help, because they only describe noise.

Condition number: when tiny changes cause big swings

Two people pushing a car from almost the same spot. You can see the car moved, but you can't tell who pushed how hard. Near-duplicate features are the same: the total effect is clear, the split between them is not.

The condition number in practice
Ratio of largest to smallest singular value: about 14,000. Huge.
Tiny change in $y$ → weights jump from $(0.96,-0.36)$ to $(1.2,-0.61)$.
But the sum stays near 0.6, so predictions barely change.
Add $\lambda I$ (ridge): condition number falls to 1,462 and the weights stay steady ($0.37,0.23$ → $0.39,0.21$).

Matrix calculus: the four rules you'll actually use

These rules are the ordinary 1-D rules ("derivative of $aw$ is $a$", "of $w^2$ is $2w$") written for many weights at once. If you know the 1-D rule, you can guess the vector one.

In one breath
Norms measure size (L1 makes lasso pick features), rank finds duplicate features, eigenvectors are the directions a matrix only stretches (PCA), the SVD finds the few hidden patterns in a table, and a large condition number warns that weights are unstable; ridge fixes it.
✎ in one line: examples are vectors, datasets are matrices, predictions are dot products, and the shapes must line up.
