Vectors & matrices

1Why bother?

A house = a list of numbers (size, bedrooms, distance). A dataset = a table of such lists. In maths a list is a vector and a table is a matrix. Almost all ML is written this way because one short line can describe operations on thousands of examples, and computers run it very fast.

2Vectors

An ordered list of numbers, e.g. $\mathbf{x}=(50,1,2)$: size 50, 1 bedroom, 2 km. It has 3 components $x_1,x_2,x_3$, so its dimension is 3: $\mathbf{x}\in\mathbb{R}^3$.

  • Picture it as a point: (3, 2) is 3 right, 2 up.
  • Or as an arrow from (0, 0): it has a direction and a length.

In ML each example is a point in "feature space", and similar examples are points close together.

3Adding and scaling

  • Add component by component: $(1,2)+(3,-1)=(4,1)$. Picture: walk along one arrow, then the other.
  • Scale every component: $3\cdot(1,2)=(3,6)$, the same direction but 3× longer. Times −1 flips it.
Where you'll see it
Gradient descent, $\mathbf{w}_{\text{new}}=\mathbf{w}-\eta\nabla L$, is just "scale one vector and subtract it from another".

4Length and distance

$\|\mathbf{v}\|=\sqrt{v_1^2+v_2^2+\dots+v_d^2}$

That's Pythagoras: $\|(3,4)\|=\sqrt{9+16}=5$. This is the Euclidean (L2) norm. The distance between two points is the length of their difference, $\|\mathbf{a}-\mathbf{b}\|$.

Example
House A = (5, 2), house B = (8, 6). Difference (3, 4) → distance 5. A "homes like this one" feature uses exactly this, and kNN (Lesson 11) too.

5The dot product (the star of ML)

Multiply matching entries, then add:

$\mathbf{a}\cdot\mathbf{b}=\sum_i a_ib_i$

Shopping bill
2 notebooks at ₹40, 3 pens at ₹10, 1 bag at ₹500 → $2\cdot40+3\cdot10+1\cdot500=610$. That's a dot product, and it's exactly how a linear model turns features and weights into a prediction.
Example
$(2,3,1)\cdot(4,-1,5)=8-3+5=$ 10. The second feature has a negative weight, so it pulls the score down; raise it from 3 to 6 and the score falls to 7.

It also measures how much two vectors point the same way: large = aligned, 0 = at right angles, negative = opposite. Dividing by both lengths gives the cosine similarity ($\cos\theta$, from −1 to 1).

6The demo

Drag the two arrows: the dot product is exactly 0 when they're at 90°.

7Matrices

A grid of numbers with shape rows × columns. The house dataset (4 houses × 3 features) is a 4 × 3 matrix $X$: each row is an example, each column a feature (the convention in scikit-learn too). $X_{32}=3$ means row 3, column 2 (house 3 has 3 bedrooms).

8Matrix × vector: all predictions at once

$X\mathbf{w}$ = each row dotted with $\mathbf{w}$.

Example from the lesson
Rows (size, bedrooms, age), $\mathbf{w}=(3,20,-5)$:
row 1: $3\cdot50+20\cdot1-5\cdot2=160$, then 255, 360, 515.
One expression $\hat{\mathbf{y}}=X\mathbf{w}$ gives every house's prediction. Add a bedroom to house 1 → its prediction rises by exactly 20 (160 → 180).

9Matrix × matrix

Every row of $A$ dotted with every column of $B$. $A$ ($m\times n$) times $B$ ($n\times p$) gives $m\times p$.

Example
$\begin{bmatrix}1&2\\3&4\end{bmatrix}\begin{bmatrix}5&6\\7&8\end{bmatrix}=\begin{bmatrix}19&22\\43&50\end{bmatrix}$ (e.g. $19=1\cdot5+2\cdot7$).
Swap the order: $BA=\begin{bmatrix}23&34\\31&46\end{bmatrix}$. Order matters: $AB\ne BA$.
Shape check
(m × n)(n × p) → (m × p). The inner sizes must match, e.g. (3×4)(4×2) → 3×2.

10Transpose and identity

  • Transpose $A^\top$: rows become columns (2×3 → 3×2). It mostly appears to make shapes line up: $\mathbf{a}^\top\mathbf{b}$, $X^\top X$ in Lesson 6.
  • Identity $I$: 1s on the diagonal, 0s elsewhere. Acts like the number 1: $I\mathbf{x}=\mathbf{x}$.

11In NumPy

Arrays for vectors and matrices; @ is matrix multiplication (or a dot product for two vectors); * is element-by-element. A.T is the transpose, np.eye(3) the identity.

★Going deeper: linear algebra behind ML

Other ways to measure size: norms

  • L2 $\sqrt{\sum v_i^2}$: straight-line length; big entries count a lot (squared).
  • L1 $\sum|v_i|$: "city-block" distance; every entry counts in proportion.
  • L∞ $\max|v_i|$: only the biggest entry counts.
  • Frobenius (matrices): the L2 norm of all entries in one long list.
Example
$\mathbf{v}=(3,-4,1)$: L1 = 8, L2 = $\sqrt{26}\approx5.099$, L∞ = 4.

Why it matters: ridge penalises L2 and shrinks all weights a little; lasso penalises L1 and pushes some to exactly 0 (Lesson 10). The L1 "unit ball" is a diamond with sharp corners on the axes; L2's is a circle.

Independence, rank, determinant

Columns are independent if none can be built from the others. The rank = the number of independent columns. Least squares needs $X^\top X$ invertible, which only happens when the columns are independent.

The determinant = how much a square matrix scales areas. $\det=0$ → it squashes space flat and has no inverse.

Example
If feature 3 = feature 1 + feature 2, only 2 columns carry information: rank 2, $\det(X^\top X)=0$ (the dummy-variable trap of Lesson 6). For $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$, $\det A=2\cdot3-1\cdot1=5$: areas get 5× bigger.

Eigenvalues and eigenvectors

An eigenvector is a direction the matrix only stretches, never turns: $A\mathbf{v}=\lambda\mathbf{v}$. $\lambda$ = how much.

Example
For the $A$ above, $\det(A-\lambda I)=\lambda^2-5\lambda+5=0$ → $\lambda\approx1.382$ and $3.618$. For 3.618 the eigenvector is about $(0.526,0.851)$, and the two eigenvectors are at right angles.
Why PCA works
Every symmetric matrix has real eigenvalues and perpendicular eigenvectors ($A=Q\Lambda Q^\top$). Covariance matrices are symmetric, so PCA's components are their eigenvectors (Lesson 17). Use np.linalg.eigh for symmetric matrices.

Positive definite matrices

$\mathbf{x}^\top A\mathbf{x}>0$ for every non-zero $\mathbf{x}$ (all eigenvalues positive). $X^\top X$ is always at least positive semi-definite, because $\mathbf{w}^\top X^\top X\mathbf{w}=\|X\mathbf{w}\|^2\ge0$. That's why the squared-error loss is a bowl with one lowest point (Lesson 3's Going deeper).

The SVD

Works for any matrix, including a data table: $A=U\Sigma V^\top$. The singular values in $\Sigma$ rank how important each hidden direction is, and keeping the top $k$ gives the best possible rank-$k$ approximation (Eckart–Young).

Example from the lesson
50 users × 40 films, secretly built from 3 hidden "tastes" plus noise. The singular values drop sharply after the third (38.5, then 3.9): the SVD found the 3 tastes. A rank-3 version stores 273 numbers instead of 2,000, with relative error 0.157 (mostly the noise). Recommender systems use this idea (Lesson 27).

Nearly duplicate features: the condition number

When two features are almost copies of each other, the matrix is close to losing rank. Its condition number (largest ÷ smallest singular value) becomes huge, and tiny changes in the data swing the weights wildly. Regularization (Lesson 10) calms this down.
