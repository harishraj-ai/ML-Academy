Part 1 · Lesson 1

What is machine learning?

1What you'll get from this lesson

Explain in plain words what ML is, how it differs from normal programming, and what model, feature, label, training and prediction mean. No maths or programming needed.

2Two ways to make a computer smart

Goal: a program that spots spam emails.

Way 1: write the rules
"if the email contains 'free money' → spam…". Works for simple problems, but spammers change their wording and there are thousands of special cases. You can never write them all.
Way 2: show examples
Collect 100,000 emails already marked spam / not spam. A learning algorithm finds the patterns and produces a program that classifies new emails. That's machine learning.

Google's definition: ML is "a way to train software, called a model, to make predictions or generate content using data".

Like a child learning "dog"
Nobody gives a child a rulebook (four legs, fur, barks…). They see many dogs and many not-dogs, and work it out.

3You already use ML every day

Keyboard next-word suggestions, travel-time estimates in maps, "watch next" recommendations, card-fraud alerts, photo apps grouping faces, chatbots. Same core every time: a model turns an input into an output.

4The essential vocabulary

Running example: predicting house prices.

  • Example (sample, row): one house.
  • Features $x$: what we know, e.g. $x=(50,1,2)$.
  • Label $y$: what we want to predict (the price, 210).
  • Dataset: the whole table.
  • Model: a function from features to a prediction $\hat{y}$ ("y-hat" = our guess).
  • Parameters (weights): the adjustable numbers inside the model.
  • Training: adjusting the parameters so predictions match the labels.
  • Inference: using the trained model on new examples.
Notation: $x$ features · $y$ true label · $\hat{y}$ prediction · $n$ number of examples · $d$ number of features · $x_3, y_3$ = the 3rd example.

5Types of machine learning

  • Supervised (has labels):
    • Regression: the label is a number (price → 340).
    • Classification: the label is a category (spam? yes/no; which digit 0–9?).
  • Unsupervised (no labels): find structure, e.g. clustering customers into groups, or dimensionality reduction.
  • Reinforcement learning: an agent acts, gets rewards or penalties, learns by trial and error (game-playing programs).
  • Generative AI: creates new text, images or audio (chatbots, image generators).

This course focuses on supervised and unsupervised learning, the foundation for everything else.

Careful!
"Logistic regression" is a classification method. Go by what you predict, not the name.

6How a model "learns"

Simplest model: price from size with a straight line.

$\hat{y}=w\cdot x+b$

$w$ (weight / slope) = how much the price rises per extra m²; $b$ (bias / intercept) = the starting price. Learning = finding the best $w$ and $b$. Three ingredients:

  1. A model with adjustable parameters.
  2. A loss: how wrong it is.
  3. An optimisation method that changes the parameters to reduce the loss.

The usual loss for numbers is the mean squared error: square each error (all positive, big misses count more), then average.

$\text{MSE}=\dfrac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2$

Example
Predictions 3 and 5, true values 4 and 5 → errors −1 and 0 → squared 1 and 0 → MSE = 0.5.

7Be the algorithm (the demo)

Move the $w$ and $b$ sliders to fit the dots and watch the MSE shrink. Adjust → check the loss → adjust again: that's exactly what a learning algorithm does, just with precise maths, millions of times faster, and with thousands of parameters instead of two.

8The ML workflow

  1. Define the problem: what to predict, how to measure success.
  2. Collect data.
  3. Split: keep a test set the model never sees (Lesson 5).
  4. Prepare: clean errors, fill gaps, turn categories into numbers (Lesson 20).
  5. Train: start simple, then try better models.
  6. Evaluate on unseen data (Lesson 9).
  7. Deploy and monitor.
The one big trap: overfitting
A model can memorise its training data, like a student memorising last year's exam answers. Perfect on seen data, fails on new data. Avoiding this is a central theme of the course.
✎ in one line: show it examples, let it tune its parameters to make the loss small, and judge it on new data.
