Graph data & network analysis

1When connections are the data

Who follows whom, which accounts pay which, which papers cite which, which products are bought together. Treating each row alone throws away the most useful part: a fraudster's account looks ordinary on its own, but it's connected to a ring of new accounts; churn risk rises when friends leave. A graph = nodes joined by edges.

2Representing a graph

Adjacency matrix $A_{ij}=1$ if connected (symmetric if undirected). A node's degree = its row sum (B has 3). Large graphs: edge lists or sparse matrices (almost all entries are 0). Keep direction when it matters (A paid B ≠ B paid A).

Example from the lesson
100 people in 3 hidden communities: of 357 edges, 332 are inside communities and only 25 cross.

3Who matters? Centrality

  • Degree: how many connections.
  • PageRank: important if important nodes link to you. A random surfer follows a link with probability $d$ (≈ 0.85) or jumps anywhere; PageRank = share of time spent at each node.
  • Closeness: how near you are to everyone (1 / mean shortest-path distance).
  • Betweenness: how often you sit on others' shortest paths (a bridge).

$r_j=\dfrac{1-d}{n}+d\sum_{i\to j}\dfrac{r_i}{\text{out-degree}(i)}$

4The PageRank demo

Circle size = PageRank. Change the damping factor, or cut the top node's links and watch importance move elsewhere.

5Communities

Groups densely connected inside. Modularity = fraction of edges inside groups minus what random wiring with the same degrees would give:

$Q=\dfrac{1}{2m}\sum_{ij}\Big(A_{ij}-\dfrac{k_ik_j}{2m}\Big)[c_i=c_j]$

Near 0 = no structure; above ~0.3 = clear communities. Found with Louvain/Leiden (greedy modularity) or spectral clustering (eigenvectors of the graph). In the lesson, spectral clustering recovers the three communities almost perfectly.

6Predicting missing links

  • Common neighbours: how many friends two people share.
  • Adamic–Adar: shared neighbours weighted by $1/\log(\text{degree})$; a shared friend with few friends says more than a shared celebrity.
  • Preferential attachment: product of the degrees (busy nodes gain more links).
Example
Hide 10% of edges, score them against unconnected pairs: common neighbours AUC 0.613, Adamic–Adar 0.605, better than chance. Preferential attachment doesn't fit this graph: check which mechanism fits yours.

7Graph features for ordinary models

Easiest use: compute features (degree, PageRank, community, clustering coefficient, neighbours' averages) and add them to a normal model.

Homophily
Connected nodes tend to be alike. Adding contacts' average signal raised accuracy from 63.0% to 72.0%: neighbours average out each person's noise. Graph neural networks build on this idea.
Only use neighbour labels that would really be known at prediction time.

8In practice

  • Node importance (influencers, critical servers): degree, PageRank, betweenness.
  • Communities (segments, fraud rings): Louvain/Leiden, spectral.
  • Link prediction (suggestions): common neighbours, Adamic–Adar, embeddings.
  • Node classification (fraud, bots): graph features + classifier, label propagation, GNNs.
  • Paths and flows (deliveries, supply chains): shortest paths, max-flow.

networkx for small and medium graphs; graph databases and PyTorch Geometric for big ones.

★Going deeper: PageRank as an eigenvector, and the graph Laplacian

PageRank is an eigenvector

Pour water into a network of pipes and let it flow for a long time. Eventually the amount in each tank stops changing: water flowing in equals water flowing out. That steady state is PageRank.

Two pages, by hand ($d=0.85$)
A links to B and B links to A. Start $r=(0.9,0.1)$.
Step: each page gets $0.15/2=0.075$ plus $0.85\times$ the other's share.
A: $0.075+0.85\times0.1=0.16$; B: $0.075+0.85\times0.9=0.84$.
Repeating, the swing shrinks by 0.85 each step and settles at $(0.5,0.5)$.

The graph Laplacian

Give every node a number so that linked nodes get similar numbers. The smoothest pattern that isn't "everyone the same" naturally changes sign across the graph's weakest bridge, splitting it into two communities.

A path of three nodes A–B–C
Values $f=(1,0,-1)$: $(1-0)^2+(0-(-1))^2=2$.
Values $f=(1,1,1)$: 0, the constant pattern, always eigenvalue 0.
The smoothest non-constant pattern changes sign once, splitting the path into two sides.
In one breath
PageRank is the steady state of the random surfer, the eigenvector with eigenvalue 1, found reliably by power iteration; and the Laplacian's second eigenvector gives the smoothest split of a graph, the basis of spectral clustering.
✎ in one line: store it sparsely, measure who matters, find the communities, and use neighbours as features.
