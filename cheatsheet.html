Reference

Formula cheat sheet

Every key formula from the 21 lessons on one page. Click a lesson tag (L6) to jump to the full explanation. Prints neatly on paper or to PDF.

Notation

DataL2$X \in \mathbb{R}^{n\times d},\ \mathbf{y} \in \mathbb{R}^n$
n examples (rows), d features (columns)
PredictionL1$\hat{y}$
the model's guess for y
Learning rate / regularizationL7$\eta,\ \lambda$
step size; penalty strength

Linear algebra

Dot productL2$\mathbf{a}\cdot\mathbf{b} = \sum_i a_ib_i = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$
Euclidean normL2$\|\mathbf{v}\| = \sqrt{\textstyle\sum_i v_i^2}$
Cosine similarityL2$\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}$
All predictionsL2$\hat{\mathbf{y}} = X\mathbf{w}$
shapes: (n×d)(d) = (n)

Calculus

Power ruleL3$\tfrac{d}{dx}x^n = nx^{n-1}$
Chain ruleL3$\tfrac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$
Gradient descentL7$\mathbf{w} \leftarrow \mathbf{w} - \eta\,\nabla L(\mathbf{w})$

Probability & statistics

Bayes' theoremL4$P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}$
Mean, varianceL4$\mu = \tfrac1n\sum x_i,\quad \sigma^2 = \tfrac1n\sum (x_i-\mu)^2$
z-scoreL4$z = \frac{x-\mu}{\sigma}$
Normal ruleL4$68\% / 95\% / 99.7\%\ \text{within}\ 1/2/3\,\sigma$

Regression

Linear modelL6$\hat{y} = \mathbf{w}\cdot\mathbf{x} + b$
MSEL6$\tfrac1n\sum(\hat{y}_i - y_i)^2$
Least-squares slopeL6$w = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2},\ b = \bar{y} - w\bar{x}$
Normal equationL6$\mathbf{w} = (X^\top X)^{-1}X^\top\mathbf{y}$
MSE gradientL7$\tfrac{\partial L}{\partial w} = \tfrac2n\sum(\hat{y}_i-y_i)x_i$
R²L6$1 - \frac{\sum(y_i-\hat{y}_i)^2}{\sum(y_i-\bar{y})^2}$

Classification

SigmoidL8$\sigma(z) = \frac{1}{1+e^{-z}}$
Log lossL8$-[\,y\ln p + (1-y)\ln(1-p)\,]$
Logistic gradientL8$\tfrac{\partial L}{\partial w_j} = \tfrac1n\sum(p_i - y_i)x_{ij}$
SoftmaxL8$\frac{e^{z_k}}{\sum_j e^{z_j}}$

Evaluation

Precision / recallL9$\frac{TP}{TP+FP},\quad \frac{TP}{TP+FN}$
F1L9$\frac{2\,TP}{2\,TP+FP+FN}$
AccuracyL9$\frac{TP+TN}{TP+TN+FP+FN}$
FPRL9$\frac{FP}{FP+TN}$
x-axis of the ROC curve

Regularization

Ridge (L2)L10$\sum(y_i-\hat{y}_i)^2 + \lambda\sum w_j^2$
Lasso (L1)L10$\tfrac{1}{2n}\sum(y_i-\hat{y}_i)^2 + \lambda\sum|w_j|$
Bias–varianceL10$\text{Error} = \text{Bias}^2 + \text{Variance} + \sigma^2$

Classic algorithms

Euclidean distanceL11$\sqrt{\textstyle\sum_j(a_j-b_j)^2}$
kNN
Naive BayesL12$\hat{y} = \arg\max_y P(y)\prod_j P(x_j\mid y)$
Laplace smoothingL12$\frac{\text{count}(w,y)+1}{\text{total}(y)+|V|}$
Gini / entropyL13$1-\sum p_k^2,\quad -\sum p_k\log_2 p_k$
AdaBoost voteL14$\alpha = \tfrac12\ln\frac{1-\varepsilon}{\varepsilon}$
SVM objectiveL15$\tfrac12\|\mathbf{w}\|^2 + C\sum\max(0,\,1-y_i(\mathbf{w}\cdot\mathbf{x}_i+b))$
margin = 2/‖w‖
RBF kernelL15$K(\mathbf{x},\mathbf{z}) = e^{-\gamma\|\mathbf{x}-\mathbf{z}\|^2}$

Unsupervised

k-means inertiaL16$\sum_i \min_j \|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2$
SilhouetteL16$s = \frac{b-a}{\max(a,b)}$
PCAL17$\Sigma\mathbf{v} = \lambda\mathbf{v},\quad \text{explained}_j = \lambda_j / \textstyle\sum\lambda$

Deep learning

NeuronL18$a = g(\mathbf{w}\cdot\mathbf{x} + b)$
Backprop (output)L18$\delta_{\text{out}} = p - y,\quad \delta_j = \delta_{\text{out}}\,v_j\,g'(z_j)$
Conv output sizeL19$\frac{W - F + 2P}{S} + 1$
AttentionL19$\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$
